작은 컨테이너

sample.bf의 형식은 BF01(4바이트), 압축 전 길이(4바이트 big-endian), zlib 데이터입니다. 길이를 읽고 본문을 최대 4096바이트로 제한해 해제하세요.

해결 목표

헤더·길이·압축 본문의 경계를 읽어 FLAG를 복원합니다.

FLAG 형식은 BIFROST{...}입니다. 대소문자와 중괄호를 그대로 입력하세요.

미해결

개인 학습용 문제입니다. 해결 기록은 이 브라우저에 저장됩니다. FLAG 일치와 독립 풀이 능력은 별도로 확인하세요.

단계별 힌트

먼저 시도한 내용과 막힌 위치를 적고 필요한 힌트만 여세요.

힌트 1

파일 전체를 UTF-8로 읽지 말고 read_bytes로 읽으세요.

힌트 2

int.from_bytes(raw[4:8],'big')가 선언 길이입니다.

힌트 3

raw[8:]을 decompressobj().decompress(data,4096)로 해제하고 eof·길이·남은 데이터를 확인하세요.

시도 후 풀이 확인

magic 확인 → big-endian 길이 → 한도 있는 zlib 해제 → 길이·eof 확인. 출력 한도가 있다는 이유만으로 모든 파일을 안전하게 처리한다고 일반화하지 않습니다.

풀이를 읽었다면 새 입력으로 재현한 뒤 관련 차시에 독립 수행 여부를 기록하세요.

채점과 기록의 범위

정적 사이트의 브라우저 검증이므로 자료·검증 정보는 공개되어 있으며 우회가 가능합니다. 공개 경쟁·실력 인증용 채점이 아닙니다. 계정 동기화는 없고 브라우저 데이터 삭제 전 기록을 백업하세요.
