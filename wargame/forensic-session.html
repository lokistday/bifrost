S7 세션의 흔적

실제 SQLite 파일 events.sqlite에서 session=S7이며 action=read인 기록의 fragment를 seq 순서로 복원하세요. 원본 복사본을 읽기 전용으로 조사하세요.

해결 목표

SQL 필터와 순서를 근거로 FLAG를 복원합니다.

FLAG 형식은 BIFROST{...}입니다. 대소문자와 중괄호를 그대로 입력하세요.

미해결

개인 학습용 문제입니다. 해결 기록은 이 브라우저에 저장됩니다. FLAG 일치와 독립 풀이 능력은 별도로 확인하세요.

단계별 힌트

먼저 시도한 내용과 막힌 위치를 적고 필요한 힌트만 여세요.

힌트 1

Python sqlite3 또는 SQLite 도구로 events 테이블을 확인하세요.

힌트 2

WHERE session='S7' AND action='read' 조건이 필요합니다.

힌트 3

ORDER BY seq를 적용하고 fragment만 결합하세요. 파일에 보이는 문자열 순서와 사건 순서를 혼동하지 마세요.

시도 후 풀이 확인

SELECT fragment FROM events WHERE session='S7' AND action='read' ORDER BY seq. 관찰된 세션 기록에서 복원했으며 실제 사용자 의도까지 증명하지 않습니다.

풀이를 읽었다면 새 입력으로 재현한 뒤 관련 차시에 독립 수행 여부를 기록하세요.

채점과 기록의 범위

정적 사이트의 브라우저 검증이므로 자료·검증 정보는 공개되어 있으며 우회가 가능합니다. 공개 경쟁·실력 인증용 채점이 아닙니다. 계정 동기화는 없고 브라우저 데이터 삭제 전 기록을 백업하세요.
