변환을 거꾸로

python3 lock.py로 프로그램을 실행하세요. 비교 직전의 바이트 변환을 역으로 적용해 올바른 key를 찾아 입력하세요.

해결 목표

역순과 XOR의 역연산으로 입력을 복원합니다.

FLAG 형식은 BIFROST{...}입니다. 대소문자와 중괄호를 그대로 입력하세요.

문제 자료 ZIP ↓
다운로드 무결성 확인

SHA-256: fd927cb11ee8002be792787c2e61e605ac859746072eb93ff7c86893208984c7

막히면 먼저 볼 차시

  • 문자열은 단서, 결론은 가설 ↗
  • 변환 연산과 데이터 의존성 역추적 ↗

실행 환경·파일·출력이 예상과 다를 때 ↗

FLAG 제출

미해결

개인 학습용 문제입니다. 해결 기록은 이 브라우저에 저장됩니다. FLAG 일치와 독립 풀이 능력은 별도로 확인하세요.

단계별 힌트

먼저 시도한 내용과 막힌 위치를 적고 필요한 힌트만 여세요.

힌트 1

비교 대상은 평문 문자열이 아니라 변환된 바이트 목록입니다.

힌트 2

XOR 0x23을 다시 적용하면 원래 바이트가 됩니다.

힌트 3

XOR을 되돌린 뒤 바이트 순서를 뒤집고 ASCII로 읽으세요.

시도 후 풀이 확인

비교 목록의 각 값에 0x23을 XOR하고 역순으로 읽으면 BRIDGE입니다. 입력해 출력된 FLAG를 제출합니다.

풀이를 읽었다면 새 입력으로 재현한 뒤 관련 차시에 독립 수행 여부를 기록하세요.

채점과 기록의 범위

정적 사이트의 브라우저 검증이므로 자료·검증 정보는 공개되어 있으며 우회가 가능합니다. 공개 경쟁·실력 인증용 채점이 아닙니다. 계정 동기화는 없고 브라우저 데이터 삭제 전 기록을 백업하세요.
