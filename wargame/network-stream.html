두 패킷의 메시지

Wireshark에서 capture.pcap을 열고 192.0.2.8에서 목적지 UDP 9000으로 보낸 페이로드를 순서대로 읽으세요. 모두 합성 문서용 주소이며 실제 통신은 하지 않습니다.

해결 목표

출발지·포트 필터와 페이로드 순서를 이용해 FLAG를 복원합니다.

FLAG 형식은 BIFROST{...}입니다. 대소문자와 중괄호를 그대로 입력하세요.

문제 자료 ZIP ↓
다운로드 무결성 확인

SHA-256: cbd846d0f3513187466b9a8ffe05c8119c4c7d37508a0015a542365358eabcf0

실행 환경·파일·출력이 예상과 다를 때 ↗

FLAG 제출

미해결

개인 학습용 문제입니다. 해결 기록은 이 브라우저에 저장됩니다. FLAG 일치와 독립 풀이 능력은 별도로 확인하세요.

단계별 힌트

먼저 시도한 내용과 막힌 위치를 적고 필요한 힌트만 여세요.

힌트 1

ip.src == 192.0.2.8 && udp.dstport == 9000으로 필터링합니다.

힌트 2

UDP 상세 아래 Data 또는 Follow UDP Stream을 확인하세요.

힌트 3

선택한 두 프레임의 데이터만 시간 순서대로 결합합니다.

시도 후 풀이 확인

지정된 출발지의 두 UDP 데이터 조각을 이어 붙입니다. 다른 출발지의 noise는 제외합니다. 암호화되지 않은 UDP 표본입니다.

풀이를 읽었다면 새 입력으로 재현한 뒤 관련 차시에 독립 수행 여부를 기록하세요.

채점과 기록의 범위

정적 사이트의 브라우저 검증이므로 자료·검증 정보는 공개되어 있으며 우회가 가능합니다. 공개 경쟁·실력 인증용 채점이 아닙니다. 계정 동기화는 없고 브라우저 데이터 삭제 전 기록을 백업하세요.
