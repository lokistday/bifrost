한 바이트의 열쇠

cipher.hex는 ASCII 메시지의 모든 바이트에 같은 1바이트 키를 XOR한 결과입니다. 메시지가 BIFROST{로 시작한다는 단서를 이용하세요. 실제 보안 암호화가 아닌 고전적인 모형입니다.

해결 목표

알려진 평문의 첫 바이트로 XOR 키를 구하고 전체 메시지를 복원합니다.

FLAG 형식은 BIFROST{...}입니다. 대소문자와 중괄호를 그대로 입력하세요.

문제 자료 ZIP ↓

SHA-256: 40dd40a7fbca00f774099beefaacb72e374289a8c56a2ed4b24eb8a8dac2cea4

미해결

개인 학습용 문제입니다. 해결 기록은 이 브라우저에 저장됩니다. FLAG 일치와 독립 풀이 능력은 별도로 확인하세요.

단계별 힌트

먼저 시도한 내용과 막힌 위치를 적고 필요한 힌트만 여세요.

힌트 1

bytes.fromhex로 hex 문자열을 바이트로 바꿉니다.

힌트 2

첫 암호 바이트 XOR ord('B')가 키입니다.

힌트 3

구한 키를 모든 바이트에 XOR하고 ASCII로 읽습니다.

시도 후 풀이 확인

키는 0x37입니다. bytes(b ^ key for b in cipher)를 복호합니다. Base64·XOR과 현대 인증 암호의 보장을 구분하세요.

풀이를 읽었다면 새 입력으로 재현한 뒤 관련 차시에 독립 수행 여부를 기록하세요.

채점과 기록의 범위

정적 사이트의 브라우저 검증이므로 자료·검증 정보는 공개되어 있으며 우회가 가능합니다. 공개 경쟁·실력 인증용 채점이 아닙니다. 계정 동기화는 없고 브라우저 데이터 삭제 전 기록을 백업하세요.
