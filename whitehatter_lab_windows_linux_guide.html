Windows에서 Linux 시작하기

Windows를 지우거나 컴퓨터를 새로 설치할 필요 없이 Linux 명령어와 보안 학습 도구를 익힐 수 있습니다. 처음 시작한다면 대부분의 경우 WSL 2와 Ubuntu 조합이 가장 간단합니다.

01 / CHOOSE YOUR ENVIRONMENT

어떤 방법으로 시작하면 좋을까?

처음에는 복잡한 구성을 만들기보다, 터미널을 열고 기본 명령어를 실행할 수 있는 환경부터 준비하세요.

초보자 추천

WSL 2 + Ubuntu

Windows 안에서 Linux 환경을 실행합니다. Windows와 Linux 도구를 함께 사용하기 편하고, 기초 터미널·Python·Git·네트워크 학습에 적합합니다.

추천 상황: Windows를 주 운영체제로 유지하면서 Linux 명령어부터 배우고 싶을 때.

별도 환경 필요

가상 머신(Virtual Machine)

VirtualBox 같은 프로그램 안에 Ubuntu 전체 운영체제를 설치합니다. 데스크톱 환경이나 가상 네트워크 구성이 필요한 실습에 유용하지만 메모리와 디스크 공간이 더 필요합니다.

추천 상황: 별도 Linux 데스크톱이나 격리된 실습용 VM이 필요할 때.

추천 경로: WSL 2 설치 → Ubuntu 터미널 익숙해지기 → Python/Git → 필요해질 때 가상 머신 추가. 처음부터 듀얼 부팅을 구성할 필요는 없습니다.
02 / WSL 2 SETUP

WSL 2와 Ubuntu 설치하기

아래 단계는 지원되는 Windows 10/11 환경을 기준으로 합니다. Windows 버전과 장치 정책에 따라 메뉴나 안내 문구가 조금 다를 수 있습니다.

Windows 버전 확인

Windows Update를 열어 가능한 최신 업데이트를 적용합니다. 회사·학교에서 관리하는 PC라면 WSL 설치 권한이 제한될 수 있습니다.

시작 메뉴에서 PowerShell을 검색합니다. 설치 명령을 실행할 때는 관리자 권한이 필요할 수 있습니다.

WSL 설치 명령 실행

PowerShell을 관리자 권한으로 열고 아래 명령을 실행합니다.

wsl --install

기본 Linux 배포판으로 Ubuntu가 설치되는 경우가 많습니다. 다른 배포판을 선택할 수 있는 환경이라면 설치 가능한 배포판을 먼저 확인할 수도 있습니다.

wsl --list --online

재시작하고 Ubuntu 첫 실행

Windows가 재시작을 요청하면 재시작합니다. 시작 메뉴에서 Ubuntu를 실행하고, 첫 설정에서 Linux 사용자 이름과 비밀번호를 만듭니다.

Linux 비밀번호 입력 중에는 화면에 글자가 표시되지 않는 것이 정상입니다. Windows 계정 비밀번호와 별개로 설정할 수 있습니다.

설치 상태와 버전 확인

PowerShell에서 WSL 상태와 배포판을 확인합니다.

wsl --status
wsl --list --verbose

배포판의 VERSION이 2인지 확인합니다. 필요할 때는 설치된 배포판 이름을 확인한 뒤 아래 형식으로 버전을 지정할 수 있습니다.

wsl --set-version Ubuntu 2

배포판 이름은 장치에 표시된 실제 이름을 사용하세요.

Ubuntu 패키지 목록 업데이트

Ubuntu 터미널에서 다음 명령을 실행합니다.

sudo apt update
sudo apt upgrade

sudo는 관리자 권한으로 명령을 실행할 때 사용합니다. 비밀번호를 묻는 경우 Ubuntu를 처음 설정할 때 만든 Linux 비밀번호를 입력합니다.

03 / FIRST COMMANDS

처음 연습할 Linux 명령어

명령어를 한 줄씩 입력하고, 출력이 무엇을 뜻하는지 직접 설명해 보세요.

명령어역할연습 예시
pwd현재 위치 표시지금 어느 디렉터리에 있는지 확인
ls파일·폴더 목록 보기현재 폴더의 항목 확인
cd디렉터리 이동cd ~로 Linux 홈으로 이동
mkdir폴더 만들기mkdir whl-practice
cp / mv복사 / 이동·이름 변경연습용 텍스트 파일 복사해 보기
cat파일 내용 출력작은 텍스트 파일 읽기
grep텍스트에서 패턴 찾기grep "hello" sample.txt
man / --help도움말 확인ls --help

첫 번째 미니 실습

mkdir -p ~/whl-practice
cd ~/whl-practice
printf 'WHITEHATTER LAB\nLinux practice\n' > notes.txt
pwd
ls -l
cat notes.txt
grep 'Linux' notes.txt

완료 기준: 폴더를 만들고 파일을 작성한 뒤 내용을 확인하고, 각 명령어가 한 일을 자신의 말로 설명할 수 있습니다.

04 / WINDOWS & LINUX FILES

Windows 파일과 Linux 파일은 어디에 있을까?

WSL 안에서는 Linux 홈 디렉터리인 ~ 아래에 학습 폴더를 만드는 것을 권장합니다.

mkdir -p ~/projects/whitehatter-lab

Windows 드라이브는 일반적으로 Linux에서 /mnt/c/ 같은 경로로 접근할 수 있습니다. 예를 들어 C 드라이브의 파일은 /mnt/c/Users/Windows사용자이름/ 아래에 있을 수 있습니다.

초보자 팁: Linux 명령어를 많이 사용하는 프로젝트는 Linux 홈 디렉터리 안에 두면 편리합니다. Windows 앱에서 파일을 직접 편집할 때는 WSL의 파일 접근 방식과 권한 차이를 이해하고 사용하세요. 경로의 대소문자와 슬래시 방향도 Windows와 다를 수 있습니다.
05 / TROUBLESHOOTING

설치가 안 될 때 확인할 것

  • `wsl` 명령을 찾을 수 없음: Windows 업데이트 상태와 WSL 설치 여부를 확인하고, 설치 후 재시작합니다.
  • 가상화 관련 오류: 장치의 가상화 기능이 활성화되어 있는지 확인합니다. BIOS/UEFI 설정 변경은 장치 제조사 안내를 따릅니다.
  • 회사·학교 PC에서 권한 오류: 관리자 정책으로 설치가 제한됐을 수 있으므로 관리자에게 문의합니다.
  • 배포판 실행 오류: `wsl --list --verbose`로 배포판 이름과 상태를 확인하고, Windows와 WSL 업데이트를 점검합니다.
  • 공간이 부족함: 불필요한 패키지와 파일을 정리하고, 가상 머신을 사용한다면 디스크 크기와 메모리를 확인합니다.
