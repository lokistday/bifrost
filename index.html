01 / ROADMAP

방향은 일찍 정하고, 경험으로 다듬기

분야 선택을 기초 학습이 끝날 때까지 미루지 않습니다. 초반에 관심 방향을 정하고, 공통 기초와 분야 입문 실습을 병행하면서 경험에 따라 조정하세요.

STEP 00분야 탐색처음부터 시작

실력을 갖추기 전에도 관심 분야부터 정하기

지금 잘하는 분야를 고르는 것이 아닙니다. 어떤 문제를 풀고 싶은지 가볍게 살펴보고, 우선 공부할 방향을 정합니다. 경험이 쌓이면 바꿔도 괜찮습니다.

  • Web · Pwn · Rev 등 분야 살펴보기
  • 분야별 입문 과제 훑어보기
  • 관심 분야 1개와 보조 분야 1개 선택
다음 단계 기준 — 완벽한 확신이 없어도 우선 탐색할 분야를 정하고, 필요한 공통 기초를 파악할 수 있다.
STEP 01공통 기초 + 분야 입문병행해서 진행

공통 기초를 배우면서 선택 분야도 조금씩 경험하기

모든 기초를 끝낼 때까지 기다리지 않습니다. C/Python, Linux, 네트워크를 학습하면서 선택한 분야의 아주 쉬운 입문 실습을 함께 진행합니다.

  • C / Python 기초
  • Linux / Shell
  • TCP/IP · DNS · HTTP
  • 선택 분야의 첫 실습
  • Git · 학습 기록
진행 기준 — 기초를 계속 쌓으면서 선택한 분야의 실습을 조금씩 시도하고, 막히는 기초 개념을 확인한다.
STEP 02보안 공통 개념기초에서 보안으로

취약점이 생기는 이유와 방어 원리 익히기

인증·인가, 입력 검증, 메모리, 권한, 암호화의 기본 개념을 실습과 함께 학습합니다.

  • 웹 보안 기초
  • 운영체제와 권한
  • 암호학 기초
  • 로그와 트래픽
다음 단계 기준 — 취약점의 원인, 재현 조건, 방어 방법을 자신의 말로 설명할 수 있다.
STEP 03집중 학습선택 분야 심화

기초와 실습 경험을 연결해 깊이 파고들기

선택 분야의 핵심 개념과 도구를 체계적으로 익히고, 난도를 조금씩 높여 갑니다. 필요하면 처음 선택한 분야를 조정해도 됩니다.

  • 분야별 핵심 개념
  • 중급 실습과 워게임
  • 도구 사용과 분석 방법
  • 취약점 원리와 방어 관점
다음 단계 기준 — 단순히 따라 하는 수준을 넘어 문제의 원인과 해결 과정을 설명할 수 있다.
STEP 04–05프로젝트와 결과물연구 · 포트폴리오

재현 가능한 실습과 프로젝트로 역량 증명하기

선택한 분야의 난도를 높이고, 풀이를 넘어 도구·분석 보고서·검증 프로젝트로 발전시킵니다.

  • 심화 실습과 CTF
  • 코드 분석과 자동화
  • 기술 보고서
  • GitHub 포트폴리오
도달 목표 — 결과를 재현하고, 선택한 기술과 판단 근거를 다른 사람에게 설명할 수 있다.
02 / STUDY TRACKS

선택한 분야를 기초와 함께 시작하기

관심 분야는 처음부터 완벽하게 정할 필요가 없습니다. 입문 가이드를 먼저 살펴보고, 공통 기초를 배우면서 선택한 분야의 실습을 병행하세요. 체크한 진도는 현재 브라우저에 저장됩니다.

ⓘ
진도 저장 안내지금 버전은 로그인 없이 이 브라우저의 로컬 저장소에 진도를 저장합니다. 다른 기기와 동기화되거나 계정별로 저장되지는 않습니다. 회원가입·로그인과 서버 저장은 추후 단계로 확장할 수 있도록 분리합니다.
