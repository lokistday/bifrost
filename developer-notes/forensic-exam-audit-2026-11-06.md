## 150문항 편집 검토

모든 질문·정답·세 오답·해설을 해당 차시 설명 및 실제 실습과 대조했다.
문항별 정확한 원문 문단은 `forensic-exam-evidence-2026-11-06.json`에 차시 ID·절·인용문으로 기록했다.
자동 검사는 이 문단이 실제 해당 모듈의 강의에 존재하는지 확인한다. 이 검사는 의미적 정답 검토를 대신하지 않는다.

- 해시의 내용 일치 근거와 출처·사건 진실성·행위자 인증을 구분했다.
- 원본 변경을 요구하지 않고 사본·임시 폴더에서만 변경 실험을 한다.
- 단일 IP·계정·PID·inode·EventRecordID를 사람이나 영구 신원으로 확대하지 않았다.
- 시간대 오프셋, 날짜 경계, 장비 시계 오차, 수집 지연을 구분했다.
- 정렬·시간 인접성·공통 연결 키와 인과·공격 성공 확정을 구분했다.
- 표시 행수와 전체 행수, 필터 조건과 제외 ID를 구분했다.
- 가상 BF의 little-endian 길이와 PNG의 big-endian 청크 길이를 명시했다.
- Hex 문자 수와 바이트 수, 0 기반 오프셋과 순번을 구분했다.
- PNG 청크 전체 크기 계산에서는 파일 시그니처 8바이트가 포함되지 않음을 해설에 명시했다.
- PNG CRC 대상은 종류+데이터이고 길이 필드는 포함하지 않는다. CRC를 작성자 인증이나 악성 판정으로 설명하지 않았다.
- JPEG·ZIP 접두 후보, 제한된 PNG 계약 통과, 지원 밖 UNVERIFIED를 전체 형식 검증이나 위협 판정으로 확대하지 않았다.
- 실제 파일 형식, 장난감 BF 구조, 합성 XML/JSON/SQLite와 실제 획득·EVTX·RAM·브라우저 원본을 구분했다.
- Windows LogonType 3의 네트워크 로그온과 대화형 사용·실제 사용자 의도를 구분했다.
- sudo의 선행 로그인 연결·요청 허용·실행 종료를 구분했다.
- 파일 이름 수·객체 수·링크 선언 수, ctime·birth와 수집 누락을 구분했다.
- 메모리 구간은 [start,start+size)이며 끝 주소는 제외했다. private/W/X 조건과 JIT 가능성·규칙 한계를 명시했다.
- 시계 오차 구간이 겹치거나 경계가 접하면 선후 불확실로 남긴다. 양방향의 엄격한 선후도 검사했다.
- 설정 enabled=true를 자료 완전성과 같게 보지 않았고, 비활성 자료의 부재를 실행 부재로 바꾸지 않았다.
- 정답 위치는 시험마다 6/6/6/7개로 분산했다. 중복 질문·중복 보기·모듈 밖 복습 연결이 없는지 검사했다.

## 실행 검증

`tests/forensic_exam_answers_test.py`를 기존 `tests/exam_answers_test.py`에서 함께 실행하도록 연결했다.
실제 학습자용 `labs/forensic` 파일을 읽고 표준 라이브러리로 독립 계산한 결과 및 안전한 사본 변경 결과와 정답 보기를 대조한다.

1. 내용 복사·한 바이트 추가의 해시 비교, 원본 보존 확인, 거부 기록 수와 10초 간격
2. 날짜 경계 UTC 변환과 E05 시각·E01~E06 정렬
3. 실제 host 조인·UNKNOWN, PID 변경 사본, 계획 표시 범위
4. 실제 SQLite 질의의 3/2행과 B03 변경 후 3/3행, 제외 ID 확인
5. BF 후보의 선언/가용 길이와 5a3132 추가 후 XYZ12·COMPLETE
6. PNG 청크를 별도로 읽어 길이·종류·CRC를 직접 계산, 고정 시그니처 확인
7. mixed.bin의 offset=17 추출 바이트·SHA-256 일치 및 CRC 오류 거부
8. 상관 선택 4행과 W02 두 키 변경 후 5행·UTC 위치, 오프셋 없는 입력 거부
9. 대응 준비 조건과 승인 false일 때 HOLD, execution=NONE 유지
10. XML 이름 기반 필드 추출의 순서 독립성·단일 출처 중복 ID 오류
11. Linux 인증·sudo 연결과 S99 변경 사본, allow와 linked-login의 독립성
12. inode42의 이름 2개/객체 1개, 목록 누락 뒤 이름 1/선언 링크 2
13. M2 반열린 구간과 끝 주소 제외, rx 변경 후 review=0, size=0 입력 오류
14. 실제 interval 함수와 독립 산술 대조, 겹침·접함·양방향 엄격한 선후
15. uncertainty=0의 조건부 결과와 process enabled 변경이 기존 사건을 만들지 않는다는 확인

기존 `tests/forensic_signatures_test.py`의 모든 잘림 위치·잘못된 CRC·불완전 표본 검사도 실행한다.
`tests/exams.test.cjs`는 기존 시험과 새 시험 전체의 실제 생성 HTML·JS로 채점·88점 혼합 결과·오답 필터·재응시·시험 간 초안 격리·모든 차시 연결·실습 코드 보존을 검증한다.
