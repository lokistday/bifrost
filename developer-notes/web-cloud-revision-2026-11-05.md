# 웹·클라우드 개편

학습 콘텐츠 검토에 따라 웹 10개 차시와 클라우드 9개 차시를 확장했다. 기존 단순 모형 뒤에 실제 HTTP 또는 실제 정책 형식을 읽는 단계를 연결하고 실습 ZIP에 자료·안내를 포함했다.

웹: Python 표준 라이브러리 기반 loopback HTTP 앱, 두 교육 계정, salt+PBKDF2, 실제 세션 쿠키, 로그인 ID 교체·만료·서버 폐기, 소유자 인가, Origin·CSRF 토큰, 요청 필드 계약, 개인 응답 no-store, 로그인 시도 예산. 두 번째 로컬 출처로 CORS 허용/비허용 응답을 비교하고 실제 CSP 헤더와 인라인 차단을 관찰한다. 브라우저에서 로그인·소유권·CSRF·CORS·CSP 결과를 확인했다. 데이터는 메모리 표본이며 실제 사이트의 회원 시스템을 추가한 것은 아니다.

클라우드: 계정·리전·가용 영역·신원·네트워크의 기본 구조 설명, 실제 IAM JSON, 실제 Role/RoleBinding YAML과 Kubernetes List JSON, 부분집합 오프라인 판정, 정상/명시적 거부/범위 밖/네임스페이스/추가 권한/미지원 조건 과제. 선택형 kind 클러스터 적용·can-i·정리 절차를 제공한다. 로컬에 kind/kubectl/Docker가 없어 실제 클러스터 실행은 검증하지 않았다. IAM 전체 평가 엔진이나 클라우드 운영 권한 검증으로 표현하지 않는다.

검증: 5개 HTTP/정책 자동화 테스트(실제 HTTP 소켓·상태 변경 보존·세션 교체/폐기·만료·시도 제한·CORS/CSP 헤더·IAM/RBAC 경계), 기존 전체 사이트 테스트, 실습 묶음 검증. GitHub CI에도 새 테스트를 추가했다.

미포함: 운영용 영속 서버·TLS·분산 로그인 제한·실제 multipart 업로드·OAuth/OIDC·클라우드 계정 생성/유료 자원 배포. 기존 파일/SSRF/재시도/거래 실습은 유지한다.
