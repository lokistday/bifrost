## 내용 검토

- 기존 25문항과 신규 100문항의 문제·보기·정답·해설을 강의 내용과 대조했다. 검토 범위에서 오답 또는 복수 정답을 발견하지 않았다.
- 단순 용어 확인, 실행 흐름 추적, 출력 예측, 오류 원인 구분, 조건·범위 판단을 함께 구성했다.
- 각 문항은 네 개의 서로 다른 보기, 한 개의 정답 인덱스, 해설, 복습 차시를 가진다. 문항 ID 125개와 문제·코드 조합은 중복되지 않는다.
- Python의 bool/int 관계, 문자열·숫자 구분, 상하한 포함 여부, 상대 경로의 기준, 원자적 교체의 한계, 설정의 엄격한 검증 정책을 명시했다.
- 모듈 03의 TCP 기반 HTTPS는 해당 예시의 조건으로 한정했다. UDP를 사용하는 응용의 추가 신뢰성 기능과 HTTP/3를 부정하지 않는다.
- shell=False는 임의 실행 대상·옵션·권한까지 자동으로 안전하게 하는 것으로 설명하지 않는다. JSON 로그도 사건의 진실성이나 민감 정보 탐지를 자동 보장하지 않는다고 구분했다.

## 실행 검증

- 신규 코드 출력·예외 문제 27개와 기존 코드 출력 문제 1개를 독립 Python 프로세스로 실행해 정답 보기와 대조했다. 28사례 모두 일치했다.
- 실제 labs/foundation/workflow.py에 대해 원본 보존, 교체 전 실패·성공·임시 파일 정리, 설정 우선순위·빈 값·하위 계층 오류, argv 보존·상태 3·시간 초과, 로그 허용 필드·줄바꿈·bool 거부를 대조했다.
- 브라우저 채점 코드는 5개 시험 각각에서 만점·3문항 오답(88점)·오답 필터·해설·차시별 복습 링크를 검증했다. 시험별 답안 저장 키도 분리된다.
- 모든 공통 기초 강의에서 기존 객관식 확인 문제를 해당 모듈 모의고사 링크로 옮겼다. 예제 코드, 문제 파일, 따라 하는 실습과 독립 과제는 유지했다.
- npm test 및 npm run test:exams가 통과했다. 문항별 독립 실행과 실습 코드 검증은 tests/exam_answers_test.py로 다시 수행할 수 있으며 배포 검증에도 포함했다.

검증은 명시한 사례와 정적 검토 범위에 대한 결과이다. 모든 사실형 문항을 실제 OS·컴파일러에서 자동 실행한 것은 아니다. 이후 문제의 의미나 정답이 달라지는 개정은 시험 버전과 기존 기록 호환성을 함께 검토한다.
