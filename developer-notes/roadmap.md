## 2026-11-04 · 홈 BIFROST 타이틀

- 앞면은 채운 일반 글자, 뒤쪽은 한 칸 깊이의 열린 격자 구조로 표현한다. 네모난 마침표를 유지한다.
- 두께는 과하지 않게 얇게 조정한다. 사용자는 이후 타이틀을 360도로 계속 회전시킬 계획이다.
- 타이틀의 글자 윤곽과 깊이 연결선을 3D 좌표로 회전·투영한다. 앞면은 읽기 쉽게 천천히 회전하며, 뒤집힌 뒷면에서는 최대 4배 빠르게 지나가고 앞면으로 돌아오면 부드럽게 감속한다. 앞면은 채우고 뒷면은 열린 격자로 표시한다. 모션 줄이기 설정에서는 정지하며, 화면 밖·숨긴 탭에서는 애니메이션을 멈춘다.
- 메인 제목 위 LEARN / PRACTICE / BUILD 문구는 제거한다.

## 2026-11-04 · 모듈별 모의고사 순차 제작

- 공통 기초는 사용자 요청에 따라 5개 모듈 전체를 완성한다. 모듈 02~05에 각 25문항을 추가해 총 125문항으로 구성하고, 기존 25문항을 포함해 정답·해설을 검토한다. 코드 출력 및 예외 유형 28사례는 독립 Python 실행으로 대조한다.

- UI 참고: 사용자가 지정한 ESSENTIAL 앱의 모의시험 화면을 확인했다. 시험 목록은 분야별 간결한 행 목록으로, 응시는 한 화면 한 문제·이전/다음·우측 문항 번호 답안표·제출 버튼 구조로 구성한다. 기존 25문항을 길게 나열하는 응시 화면은 교체한다.

- 사용자 결정: 문제 파일과 따라 하는 실습 환경은 유지한다.
- 강의의 객관식 확인 문제를 별도 모의고사 페이지로 옮긴다. 차시별이 아닌 모듈별 25문항으로 구성한다.
- 현재 9개 분야 · 49개 모듈이므로 전체 목표는 49개 모의고사 · 1,225문항이다.
- 한꺼번에 작성하지 않고 모듈 단위로 순차 제작한다. 첫 제작 대상은 Foundation 모듈 01 ‘실습 환경과 파일’(환경 준비·경로와 작업 사본)이다.
- 완성된 모듈만 응시 가능하게 공개하고, 그 모듈의 강의 안 객관식 확인 문제를 모의고사 링크로 대체한다. 아직 제작하지 않은 모듈의 기존 문제는 전환 전까지 유지한다.
- 강의 진도와 시험 점수는 별개이며, 서버 도입 전에는 개인 학습용 브라우저 기록으로 제공한다.

## 2026-11-02 · 서버 도입 후 경쟁형 워게임으로 전환

사용자 요청:

> 지금은 워게임을 개별 학습용 문제로 만들었지만, 서버를 실제로 구동해서, 회원가입 로그인, 저장기능이 생기면 워게임도 경쟁형식으로 구현한다.

- 현재: 정적 사이트에서 개인 학습용 워게임, 브라우저 FLAG 검증, 로컬 해결 기록을 제공한다.
- 이후: 실제 서버 운영과 회원가입·로그인·서버 저장 기능을 갖춘 뒤 경쟁형 워게임을 구현한다.
- 경쟁형 전환 시 FLAG 판정·제출 기록·해결 시각·점수는 서버를 기준으로 처리하고, 계정별 기록·순위와 문제 실행 환경을 설계한다.
- 이번 배포는 현재의 개인 학습용 기능을 반영하는 작업이다. 위 서버·계정·경쟁 기능은 후속 개발 계획으로 보관한다.
