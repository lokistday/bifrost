# 워게임 설계 · 보류 기록

## 2026-11-05 결정

사용자 요청: “워게임은 설계를 메모만 해놓고 페이지 지워버리자. 지금은 이른거같아.”

현재 단계에서는 워게임을 공개 기능에서 제외한다. 강의·실습 파일·종합 프로젝트·모듈별 모의고사에 집중한다. 워게임 목록·문제 페이지·다운로드 자료·채점 스크립트는 배포하지 않고 메뉴·강의 링크·사이트맵에서도 제거한다. 브라우저에 남아 있는 과거 해결 기록을 강제로 삭제하지는 않는다.

## 이후 재개 조건

- 실제 서버 운영, 회원가입·로그인·세션과 계정별 기록 저장을 먼저 구축한다.
- 문제 읽기 → 실습 → FLAG 획득 → 제출·판정 → 풀이 및 복습 순서를 유지한다.
- 경쟁형은 서버에서 정답·제출 시각·시도·해결·점수를 판정하며 동점 순위·중복 제출·속도 제한 정책을 정한다. 브라우저의 해시 비교나 로컬 기록을 경쟁 점수의 근거로 삼지 않는다.
- 문제 실행 환경은 회원·진도 DB와 격리하고, CPU·메모리·프로세스·시간 제한과 만료·정리·초기화 정책을 갖춘다. FLAG·실습 인스턴스·사용자의 연결 관계를 서버에서 검증한다.
- 입문 문제의 단계별 힌트, 풀이 공개 시점, 관련 강의 연결을 제공한다. FLAG 정답과 독립 풀이 능력은 구분한다.
- 보관·백업·복구와 제출 기록의 일관성, 계정 권한 검사를 검증한 후 공개 범위를 결정한다.
