# 출발점 선택과 분야 선택 분리 · 2026-11-09

사용자 요청: 기존 BIFROST 디자인을 유지하며 처음에는 단계 안내형으로 시작한다. 기초 선택은 공통 기초로 바로 이동하고, 관심 분야 선택은 기존 9개 분야로 이동한다. 첨부 이미지의 빨간 표시인 왼쪽 메뉴·학습 시작 버튼·진도 패널은 분야 화면에서 제거한다.

- `/`: 기존 색상·상단 로고를 유지하고 출발점 두 개만 제시한다. 선택 화면의 3D BIFROST는 제거한다.
- `기초부터 배울게요.` → `/tracks/foundation/`.
- `관심 분야부터 볼게요.` → `/fields/`.
- `/fields/`: 확대된 회전 BIFROST와 배경, 그 아래 여유를 둔 기존 9개 분야, 출발점으로 돌아가는 링크. 이전 사이드바·학습 시작 버튼·진도 패널은 없다.
- 각 분야는 기존 `/tracks/{id}/` 과정으로 이동한다. 공통 기초를 포함한 9개 분야를 모두 유지한다.
- 두 선택지는 일반 링크다. JavaScript 없이도 이동하며, 별도 다음 버튼이나 회원가입을 요구하지 않는다.
- 기존 `index.html#mindmap` 및 `#fields` 링크는 상대 URL로 새 분야 페이지에 연결한다. JS가 없으면 해당 출발점 선택 링크로 이동한다. 외부 참고 자료는 하단에 접어 두고 기존 `#resources` 앵커를 유지한다.
- 홈에서 진도/경로/카탈로그 JS를 불러오지 않는다. 저장된 학습 기록은 읽거나 덮어쓰지 않으며 학습 페이지의 기존 진도 기능은 유지한다.
- 홈 전용 CSS·JS·로고 모션에는 독립 캐시 지문을 적용한다. 다른 강의 페이지의 공유 캐시 URL은 바꾸지 않는다.
- 새 분야 페이지를 사이트맵, 공개 패키징, CI 생성 파일 검사에 포함한다.

## 검증

전체 사이트 JavaScript 검사와 두 출발점·9개 분야 링크·복귀·이전 앵커·JS 없는 링크·GitHub Pages 하위 경로 검사. 실제 브라우저에서 관심 분야 선택/복귀/공통 기초 이동과 기존 모든 분야 링크를 확인했다. 1440px 및 390px 화면에서 배치를 점검했고 배경이 만들던 가로 넘침을 제거했다. 기존 3D 회전/뒷면 가속·모션 감소·포인터 효과 검사는 유지한다.

## 이후 회원 기능

나중에 회원가입·로그인·서버 저장이 생기면 첫 가입/첫 방문의 출발점 선택과 연결한다. 현재는 회원 기능이나 서버 세션을 추가하지 않는다. 선택 이력을 임의로 저장하거나 재방문 사용자를 자동 이동시키지 않는다. 계정 기반의 선호 분야·학습 이어가기는 별도 설계한다.
