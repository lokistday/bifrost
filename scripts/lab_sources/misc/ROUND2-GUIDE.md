# Misc · 매체 자료와 제한된 처리

Python 3.10 이상, 표준 라이브러리만 사용합니다. Linux/macOS는 `python3`, Windows PowerShell은 `py -3`로 실행합니다. 기존 자료와 가이드는 그대로 유지합니다. PPM은 직접 작성한 텍스트 픽셀 예제이며 이미지 편집이나 실제 사진의 메타데이터 분석이 아닙니다.

## 형식 층과 픽셀

- `python3 media_tools.py identify`: 바깥 GZIP-CANDIDATE, 안쪽 `Bifrost`와 줄바꿈 8바이트입니다. 1f8b 두 바이트만 있어도 후보는 같지만 구조는 유효하지 않습니다. 접두 식별과 실제 파싱을 구분하세요.
- `python3 media_tools.py ppm`: P3,2×2,Maxval255,4픽셀입니다. RGB 채널합은 각각510입니다. 첫 (255,0,0)을 (0,0,0)으로 바꾼 사본은 빨강합만255로 줄어듭니다. 표본 수 부족이나 값256은 거부합니다.
- P3 파서는 1~64 크기, Maxval1~255, 한 이미지라는 교육 범위입니다. 제공한 신뢰 가능한 작은 자료만 읽습니다. 임의의 거대한/적대적 이미지의 안전한 디코더나 EXIF 분석기가 아닙니다.

## 통계의 한계

`python3 media_tools.py frequency`는 같은 길이256에서 A반복 H0, AB반복 H1, 0~255순서 H8을 출력합니다. 단위는 경험적 bit/byte입니다. **마지막 자료는 완전히 결정적인데도 H8**입니다. ABAB와 AABB도 같은H1이므로 이 단일바이트 통계는 순서를 직접 설명하지 않습니다. 압축·암호화·무작위를 단정하는 분류기가 아니며 표본 길이·구간·형식 근거를 함께 기록합니다.

## 출력 예산과 완료

```text
python3 media_tools.py decompress --limit 32
python3 media_tools.py decompress --limit 31
```

기준 본문은 A32바이트라 첫 명령은 허용, 둘째는 output budget으로 거부됩니다. 이 CLI는 판정 결과를 출력해 두 경우 모두 종료 상태0이며, `bounded_decompress` 함수를 직접 호출했을 때 계약 위반은 ValueError입니다. 출력은 limit+1로 제한해 초과를 찾고 무제한 flush를 쓰지 않습니다. 잘린 스트림, 여분/연결된 스트림도 거부합니다.

이 모형은 이미 메모리에 있는 단일 zlib 입력만 다룹니다. 파일을 읽기 전 크기 제한·CPU시간·중첩·동시성·출력저장 정책은 별도입니다. 통과를 범용 안전 해제 보장으로 해석하지 마세요.

## 재개 체크포인트

새 파일명을 정해 다음 명령을 두 번 실행합니다.

```text
python3 media_tools.py batch --checkpoint round2-state.json
```

처음은3RUN, 다음은3SKIP입니다. `batch-jobs.json` 사본에서 J02텍스트만 `Changed`로 고치고 `--source batch-jobs-work.json`으로 실행하면 J02만RUN입니다. 체크포인트는 입력해시·변환버전·예상결과를 비교합니다. 이 작은 대문자화 모형은 캐시를 검증하려고 결과를 저렴하게 다시 계산하며 고비용작업의 성능을 측정하는 예제가 아닙니다.

원본 자료와 기존 체크포인트를 보관하세요. 고정 `.tmp` 뒤 교체는 통제된 작업 폴더·단일 작성자 전제입니다. 동시 작성자 잠금·병합·트랜잭션·fsync내구성을 보장하지 않습니다. 입력·코드·명령·환경의 출처 기록도 함께 남겨야 합니다.
