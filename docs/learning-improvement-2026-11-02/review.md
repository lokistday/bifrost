# 학습 과정 개선과 FLAG 워게임

## 구현 범위

- 기존 153개 영구 차시 ID를 보존합니다. 첫 실행은 Python만으로 시작하고 조건·반복·함수는 작은 실행 단계로 나눕니다.
- `content/lesson-plans.json`은 모든 차시의 난이도·추정 시간·준비 진단·도움말을 명시합니다. 모듈 위치를 바꿔도 난이도가 달라지지 않습니다. 시간은 개념·도구·독립 과제를 고려한 편집상 추정으로 실제 학습자 측정 전입니다.
- 차시별 준비 진단, 오류 도움말, 설명형 독립 평가와 수행 수준을 제공합니다. 일부 대표 차시의 무관한 오답 보기를 실제 오개념으로 교체했습니다. 모든 객관식 문항을 새로 저작했다고 주장하지 않습니다.
- 후반 차시는 빈 파일·최소 입력에서 시작하도록 안내하고 해설 후 새 반례로 재검증합니다. 이는 브라우저가 풀이의 독립성을 감시하거나 인증하는 기능은 아닙니다.
- 읽음·따라 함·독립 해결·재도전 필요와 복습 일정을 기존 v2 백업의 선택 필드로 저장합니다. 이전 백업은 그대로 가져올 수 있고 완료 기록을 초기화하지 않습니다.
- 다섯 목표별 경로를 최대 5차시 단위의 구간 목표·작은 결과물로 분할합니다. 기존 선행 차시·경로 주소·순서는 보존합니다.
- 프로젝트 결과 검사의 한계를 유지하며, 코드·테스트·보고서의 좋은/부족한 근거 비교와 검토 기준을 추가합니다.
- `wargame/`에는 Foundation·Web·Pwn·Reverse·Forensic·Network·Crypto·Misc·Cloud 9개 문제가 있습니다. 자료 ZIP, 단계별 힌트, 풀이, FLAG 제출, 해결 상태 필터와 기록 백업을 제공합니다.

## 워게임의 동작과 한계

FLAG 원문은 브라우저 기록과 서버에 전송하지 않습니다. SHA-256 비교로 정답을 확인하고, 문제별 제출 횟수와 최초 해결 시각만 로컬에 기록합니다. 제출 성공은 기존 강의 완료나 독립 수행 수준을 자동 변경하지 않습니다.

이 사이트는 GitHub Pages 정적 호스팅입니다. 검증 정보·저작 원본·문제 자료는 공개되어 풀이 우회가 가능합니다. 개인 학습용 기능이며 순위·인증·경쟁용 보안 채점 서버가 아닙니다. 실제 계정 기반 비공개 정답·경쟁 운영에는 별도 백엔드가 필요합니다.

문제는 직접 만든 소형 교육 자료입니다. Web은 127.0.0.1에만 바인딩하는 의도적으로 인가가 빠진 서버입니다. Pwn은 정수 폭 변환 모형이며 메모리 손상 공격을 구현하지 않습니다. 실제 SQLite·PCAP·C 컴파일 산출물과 바이트 자료를 읽는 연결 실습을 제공합니다.

## 검증

관련 테스트는 `tests/learning-improvement.test.cjs`, `tests/wargames_test.py`입니다. 후자는 9개 자료의 풀이와 FLAG 해시, ZIP 재현성을 검사하며 GCC가 있는 Linux/WSL에서는 정수 문제를 실제 컴파일·실행합니다. ZIP은 무압축·고정 메타데이터로 작성하고 SQLite 작성 버전 필드를 정규화해 OS·압축 라이브러리 차이가 배포 해시를 바꾸지 않게 합니다.

실제 학습자 완주·독립 수행·재시도 효과는 `learner-study.md`의 관찰을 실행해야 확인할 수 있습니다. 현재 이 관찰은 수행되지 않았습니다.

### 이번 실행 결과

- 기존 Node 학습·교육·도식·인트로·정적 링크·검색·경로·홈 테스트 통과. 새 학습·워게임 통합 테스트도 통과했습니다.
- 기존 실습 검사 23개는 Windows에서 번들된 암호 의존성을 사용해 모두 통과했습니다. WSL의 기존 개편 검사 10개도 모두 통과했습니다.
- 워게임 자료 풀이·해시·재현성 검사 3개는 WSL에서 모두 통과했습니다. GCC로 정상/실패 입력을 실제 실행했습니다. Windows에서는 GCC 검사 1개를 건너뛰고 WSL에서 보완했습니다.
- WSL에는 Node 실행 환경이 없어 전체 페이지 재생성 검사는 Windows에서 수행했습니다. 이 환경 제약을 학습 코드 결함으로 처리하지 않았습니다.
- 실제 브라우저에서 오답·정답 FLAG, 재방문 해결 유지, 수행 수준 기록→복습 목록, 320px 제출 폼·메뉴의 가로 넘침 없음을 확인했습니다.
- 배포용 `_site` 690개 파일을 생성했습니다. 이번 개편은 로컬 구현 상태이며 공개 사이트에는 아직 배포하지 않았습니다.
