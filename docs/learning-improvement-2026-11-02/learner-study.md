# 초보 학습자 수행 관찰

상태: 실행 전 계획. 이 문서나 자동 테스트를 학습 효과 검증 결과로 표현하지 않습니다.

## 대상과 준비

- Python·터미널 경험이 거의 없는 자원자 3~5명에게 사전 동의를 받고 진행합니다.
- 비밀번호, 실제 보안 사고 자료, 개인 식별 로그는 수집하지 않습니다. 관찰 기록에는 참여자 번호만 사용합니다.
- 학습자의 OS, Python 사용 경험, 셸 경험을 적고 자신의 컴퓨터에서 작업합니다. 관찰자는 대신 명령을 입력하지 않습니다.

## 과업

1. `foundation.environment`: Python을 확인하고 hello.py의 이름만 바꿔 재실행합니다. 편집한 파일과 실행한 파일의 경로를 설명합니다.
2. `foundation.python-values`: 문자열 "08"을 두 번 붙인 결과와 정수 8의 두 배를 예측하고 검증합니다.
3. `foundation.python-flow`: if 비교 → 두 항목 반복 → 함수로 묶기를 진행한 뒤, 빈 입력과 unknown 입력의 결과 차이를 설명합니다.
4. `wargame/foundation-log.html`: 문제 자료를 받고 CSV의 조건·정렬·레코드 경계를 읽어 FLAG를 제출합니다. 필요한 경우 선행 파일 읽기 차시까지 추가합니다. 입문 세 차시만으로 CSV 파싱을 배웠다고 가정하지 않습니다.
5. 2~3일 뒤 새 값으로 같은 과제를 다시 풀고, 과거 해설을 보았는지 기록합니다.

## 관찰 기준

- 시작·종료 시각, 설치 시간, 순수 과업 시간을 별도로 기록합니다.
- 오류 메시지, 막힌 단계, 도움말 사용, 관찰자의 개입 횟수를 기록합니다.
- 독립 해결 / 힌트 후 해결 / 해설 재현 / 중단을 구분합니다. FLAG 성공만으로 독립 해결을 판정하지 않습니다.
- 사전 예상, 실제 출력, 차이를 설명하는 문장을 수집합니다. 정답을 맞혀도 근거가 없으면 추측으로 표시합니다.
- 정해진 한 시간 내 완주를 강제하지 않습니다. 진행자가 추가 설명한 부분은 콘텐츠의 부족 후보로 기록합니다.

## 수정 판단

여러 학습자가 같은 지점에서 멈추면 그 설명·준비 순서부터 바꿉니다. 실행에 성공했지만 이유를 설명하지 못하면 중간 예측 문제를 추가합니다. 시간 추정은 중앙값과 범위를 기록하되 소표본 관찰임을 밝힙니다. 한 번의 수행으로 장기 학습 효과나 전체 보안 실무 역량을 주장하지 않습니다.
