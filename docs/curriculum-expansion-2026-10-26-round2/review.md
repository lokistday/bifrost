## 새 차시 구성

각 차시에 개념 설명, 실행 환경과 선행 차시, 전용 SVG 도식, 단계별 관찰과 예상 결과, 입력을 바꾸는 실습, 해설, 오개념, 자기 점검 문제, 공식 참고 자료를 넣습니다. 차시의 예측과 실제 실행 결과를 비교하고 정상 입력과 반례를 함께 검사합니다.

실습 원본은 `scripts/lab_sources/`, 본문은 `content/courses/`, 도식은 `content/visuals.json`에서 관리합니다. 새 자료 안내는 분야별 `ROUND2-GUIDE.md`로 분리해 이전 가이드를 보존합니다. 기존 진도 ID·저장 방식과 디자인·인트로는 유지합니다.

## 환경과 자료의 범위

외부 서비스나 실제 클라우드 자원에 접속하지 않습니다. 표본은 직접 작성한 합성 자료이며, 실제 로그·브라우저 프로필·메모리·운영 자격 증명을 수집하지 않습니다. Linux C 실습은 Ubuntu/WSL의 GCC·GDB·binutils를 사용합니다.

암호 조합 실습은 기존 선택 의존성인 `cryptography`를 재사용합니다. 공개 교육용 키와 고정 표본은 출력 비교에 사용하며 운영 키로 사용하지 않습니다. 무작위 선택의 실제 결과는 매번 달라질 수 있으므로 고정 출력과 난수 품질의 검증을 혼동하지 않습니다.

서비스 상태와 클라우드 권한은 해당 차시에 적힌 범위를 갖는 오프라인 모형입니다. 사이트의 실제 회원가입·로그인이나 운영 권한 제어 기능을 추가하는 작업이 아닙니다. 합성 Windows XML과 메모리 표본을 실제 EVTX·메모리 이미지 파서라고 표현하지 않습니다.
