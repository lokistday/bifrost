# 경로 전용 학습과 간결한 디자인 · 2026-10-29

## 동작

다섯 목표별 경로를 단순 차시 링크 모음에서 독립적으로 따라가는 과정으로 변경했습니다. 기존 강의 원본과 영구 차시 ID는 재사용합니다.

- `paths/dfir/`와 `paths/red-foundations/` 등에 전용 소개·목차를 제공합니다.
- 경로 안의 차시는 `paths/dfir/foundation.environment.html`처럼 문맥을 주소에 담습니다. 북마크·새로고침·공유·뒤로 가기에서도 주소의 경로가 유지됩니다.
- 경로명·현재 단계·전용 목차를 표시합니다. 이전·다음은 분야 순서 대신 경로의 실제 순서로 이동하며 마지막에는 같은 경로의 `project.html`로 이어집니다.
- 선행 차시 복습, 프로젝트의 준비 차시 링크도 경로 안에 유지합니다. 원래 분야 과정으로 나가는 링크는 별도로 명시합니다.
- 완료 기록은 기존 차시 ID를 공유하고, 표시하는 진도는 현재 경로에 포함된 차시만 집계합니다. 이미 학습한 동일 차시를 별도 미완료로 복제하지 않습니다.
- 경로 소개·목차·본문·이전/다음·프로젝트는 정적 HTML입니다. JavaScript 없이도 읽고 이동할 수 있습니다.

5개 경로에 소개 5개, 차시 문맥 172개, 프로젝트 5개로 총 182개 페이지를 생성합니다. 고유한 강의 내용은 기존 153개입니다. 새 차시나 별도 계정 기능을 추가한 것이 아닙니다.

## 디자인 취소 후 최종 상태

사용자의 요청으로 Hackersground 기반 시각 디자인을 취소했습니다. 기존 색상·글자 크기·카드 스타일·메인 방사형 지도 배치와 시스템 기본 테마를 복원했습니다. 전용 학습경로와 검색·목차·준비 안내의 접기 기능은 유지합니다. 아래 디자인 설명과 검사 수치는 취소 이전 작업 기록입니다. 취소 후에는 페이지를 다시 생성하고 회귀 검사합니다. 배포하지 않았습니다.

## 정보 배치와 디자인 (취소 이전 기록)

[사용자가 지정한 Hackersground](https://hackersground.kr/)의 실제 메인·신청 화면을 확인했습니다. 검정 바탕, 큰 제목, 초록 포인트, 넓은 여백과 간결한 구분선을 Bifrost에 맞춰 적용했습니다. 외부 사이트의 캐릭터·이미지·코드를 복사하지 않았습니다.

- 메인은 시작 안내와 학습 버튼을 먼저 보여 줍니다. 기존 방사형 지도와 학습 방법은 펼쳐서 확인합니다.
- 학습 도서관에서는 경로 선택에 집중합니다. 상세 목차는 각 경로 페이지에서 확인합니다.
- 전체 차시와 분야별 프로젝트 목록은 기본적으로 접습니다. 검색·필터를 쓰면 결과가 자동으로 펼쳐지고 초기화하면 다시 접힙니다.
- 경로 소개 목차는 연속한 분야별로 묶되 원래 단계 순서를 유지합니다. 첫 묶음만 열고, 차시의 옆 목차에서는 현재 묶음만 엽니다.
- 차시의 경로 안내는 짧은 표시줄로 정리했습니다. 준비·선행 정보와 백업 도구도 접어서 제공하며 첫 환경 준비 차시는 준비 안내를 엽니다.
- 저장된 라이트/다크 선택은 유지하며, 저장된 선택이 없는 첫 방문은 다크로 시작합니다. 글꼴은 로컬/시스템 글꼴을 사용합니다.
- 기존 로고·인트로·실습·도식은 유지하고 과한 카드 그림자·배경 장식을 줄였습니다.

## 원본

- `scripts/learning_design.py`: 경로 ID 검증·선행 순서·짧은 표시명
- `scripts/build_courses.py`: 공통 경로 데이터 생성
- `scripts/render_pages.cjs`, `scripts/render_study.cjs`: 경로 문맥별 정적 페이지
- `js/learning-view.js`, `js/learning.js`: 경로 목차·이동·제목 유지
- `js/path-progress.js`: 기존 완료 기록으로 경로 진도·이어서 학습 표시
- `css/editorial.css`, `css/theme.css`: 공통 시각 계층과 색상
- `scripts/package_site.py`, `.github/workflows/pages.yml`: 새 경로의 배포 묶음·생성물 확인

## 확인

전체 `pnpm test`를 통과했습니다. 경로 검사 2,993개는 172개 문맥별 차시의 실제 배포 스크립트를 실행해 이전·다음·선행 링크·제목·새로고침·완료 기록·이어서 학습·프로젝트 연결을 확인합니다. 일반 Web 과정에 직접 들어가면 원래 분야 순서가 유지되는 것도 확인했습니다.

기존 탐색/진도 22,804, 강의 3,982, 도식 4,090, 정적 링크/스타일 55,149, 학습/검색/CSP 2,370 검사와 인트로 검사도 통과했습니다. 새 레이아웃의 실제 브라우저 시각 검수를 완료했다고 표현하지 않습니다. 참고 사이트의 실제 화면 확인과 로컬 결과의 DOM·CSS 검사는 구분합니다.

현재 변경은 로컬 작업본과 `_site`에 반영했으며 원격 배포는 하지 않았습니다. 미리보기는 `http://127.0.0.1:4173/`, DFIR 과정은 `/paths/dfir/`에서 확인합니다.
