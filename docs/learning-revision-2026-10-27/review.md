# Bifrost 학습 중심 개편 · 2026-10-27

## 적용 범위

로컬 최신 9개 분야·49개 모듈·153개 차시를 개편했습니다. 영구 차시 ID, 기존 브라우저 진도 저장 키, 중앙 지도·인트로 디자인을 보존했습니다. 새 계정·원격 DB·유료 서비스·제출 서버는 추가하지 않았습니다. 원격 배포는 수행하지 않았습니다.

이 개편은 **예제 관찰 → 안내된 변경 → 독립 변형 → 두 표본의 종합 프로젝트 → 근거 보고서**를 연결합니다. '완전한 보안 교육'이나 실력·취업·실무 대응 능력을 보증하는 상태라고 표현하지 않습니다. 실제 초보 학습자의 수행·전이 능력은 별도 관찰이 필요합니다.

Crypto의 시퀀스 번호는 **AAD에도 포함**합니다. 인증되지 않은 seq를 재전송 상태의 근거로 신뢰하지 않도록 구현·변조 검사했습니다. 고정 교육용 키와 nonce는 운영용 발급 패턴이 아닙니다.

`project.py check`는 JSON 결과의 구조·타입·값을 비교합니다. 제출한 코드를 import하거나 실행하지 않고, 네트워크에 보내거나 진도를 자동 저장하지 않습니다. 자동 결과 일치가 올바른 코드 구조나 보고서 사실성을 증명하지 않음을 화면과 CLI에 명시합니다. 별도 `project-c-tests.py`는 사용자가 명시적으로 고른 C 소스를 로컬에서 컴파일·실행하며 샌드박스가 아닙니다.

## 재현됐던 문제의 처리

- **R01:** 변경 전에 기준 예제·예상 결과를 먼저 확인합니다. `hello.py` 원본의 Bifrost와 변경 사본의 Mina를 별도로 실행하고 화면 순서도 검사했습니다. C 포인터도 같은 화면 순서를 적용합니다. 모든 153개 차시를 사람처럼 처음부터 끝까지 동일 셸에서 수행했다고 주장하지 않습니다.
- **R02:** 새 임시 디렉터리에서 자료를 생성하고, `content/lab-sources.json`에 등록된 원본만 복사합니다. ZIP·해시는 그 디렉터리의 결과만 포함합니다. `labs/manifest.json`을 통해 배포 묶음도 동일한 목록만 복사합니다. 기존 로컬 작업 파일은 지우지 않으며 ZIP·배포에 넣지 않습니다.
- **R03:** 세 고급 모형의 JSON에 필수 필드·중첩 타입 검사를 추가합니다. `{}`, 잘못된 타입, bool/정수 혼동, 중복 키, 비유한 수, 과도한 크기·깊이에 오류 설명과 실패 상태를 제공합니다. 내부 KeyError 같은 프로그래밍 결함을 무조건 삼키는 처리는 하지 않습니다.
- **R04–R09:** 독립 과제·분야별 검사와 보고서, 검색·경로, 난이도/시간, 최종 프로젝트, 실제 SQLite/PCAP/ELF/암호·공식 자원 형식 연결, 실행 문맥을 추가했습니다. 기존 Network·Cloud 종합 차시는 '중간 종합'으로 이름을 명확히 했습니다.
- **R10:** 이전 실습 문자열을 `scripts/lab_sources/`로 옮겼습니다. PCAP 조립과 고정 TLS 표본 처리는 생성기에 유지합니다. 공통 입력/검사 코드는 `scripts/lab_common/`에서 복사하며 중복 저작하지 않습니다. 현재 수치와 캐시 버전은 원본에서 생성합니다.

## 적용한 보안 경계

1. **출력·DOM:** 기존 이스케이프를 유지하고 새 검색은 데이터 속성을 비교해 표시만 바꿉니다. 검색 문자열을 HTML로 삽입하지 않습니다. 검색어·답안을 전송하는 API가 없습니다.
2. **정적 CSP:** HTML의 스크립트보다 앞에 meta 정책을 배치합니다. 스크립트는 같은 출처로 제한하고 인라인 이벤트·외부 데이터 연결·플러그인·base 변경을 막습니다. 기존 Linux 안내창의 인라인 이벤트를 외부 스크립트로 옮겼습니다.
3. **CSP 한계:** 기존 SVG 스타일과 CSS 변수 때문에 스타일에는 `unsafe-inline`을 허용합니다. 같은 출처 코드의 신뢰가 전제입니다. meta로 적용되지 않는 `frame-ancestors`, HSTS, 서버 측 권한 검사 등을 설정했다고 주장하지 않습니다. GitHub Pages 응답 헤더 설정은 이 변경의 범위 밖입니다.
4. **JSON:** 일반 파일만 읽으며 최대 256KiB, 깊이 32, 노드 10,000, 문자열 8,192자 한도를 둡니다. UTF-8·중복 키·비유한 숫자·정확한 타입을 검사합니다. 공개 교육 자료용 제한입니다.
5. **배포 자료:** 승인 목록, 새 출력 공간, 심볼릭 링크/경로 이탈 검사로 실습 ZIP에 임의 잔여 파일이 들어가는 경로를 차단했습니다. 공개 키·합성 로그라는 자료의 성격을 유지합니다. 파일 해시는 출처 인증의 대체물이 아닙니다.

설계 참고: [OWASP 입력 검증](https://cheatsheetseries.owasp.org/cheatsheets/Input_Validation_Cheat_Sheet.html), [Python JSON의 자원 사용 주의](https://docs.python.org/3/library/json.html), [MDN CSP](https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Headers/Content-Security-Policy), [meta에서 frame-ancestors를 지원하지 않는 이유](https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Headers/Content-Security-Policy/frame-ancestors).

## 검증 결과

- 전체 JS/정적 회귀 검사 통과: 탐색·진도 22,476, 정적 강의·하이드레이션 3,982, 기존 도식 4,090, 정적 링크/스타일/메타데이터 22,750, 새 학습/검색/CSP 2,368 검사. 기존 인트로 검사도 통과했습니다.
- 기존 실습 검사 23개 통과: 선택 암호 패키지를 포함한 실제 AES-GCM·Ed25519·TLS 검증, ZIP/해시, 반복 빌드 재현성.
- WSL/Linux에서 기존 확장 검사 148개와 새 개편 검사 9개 모두 통과, 건너뛴 검사 없음. 새 9개 테스트 메서드에는 18개 A/B 결과와 정상/오류/변조 하위 사례가 들어 있습니다.
- 새 검사는 독립적으로 계산한 기대값, A 답안의 B 오용 거부, bool/정수 혼동, 악성/큰 JSON, 시퀀스 변조 거부, 실제 SQLite 읽기와 덮어쓰기 방지, GCC/Sanitizer 파서 검사, 역공학 -O0/-O2 비교를 포함합니다.
- 임시 복제본에서 임의 출력 파일과 미등록 원본을 주입한 뒤 ZIP·해시·공개 목록에 포함되지 않고 원래 로컬 작업 파일은 보존됨을 확인했습니다.
- 기존 `tests/c_labs.sh` 통과. Windows에서는 GCC 관련 새 검사 2개가 건너뛰어졌고 WSL에서 둘 다 실제 실행했습니다.
- 최종 `_site`에 478개 파일을 묶었습니다. 실습 공개 파일은 승인 목록 245개와 manifest만 포함하는지 대조했습니다. 로컬 HTTP에서 학습 도서관·보충 자료·대표 프로젝트·차시의 200 응답과 CSP 메타데이터를 확인했습니다.

실제 브라우저의 새 화면 배치·키보드 동선은 이번에 자동 확인하지 않았습니다. 정적 DOM·링크·CSS 파싱 검사를 실제 브라우저 시각 검수라고 표현하지 않습니다. 자동 검사가 학습 효과를 입증하지도 않습니다.
