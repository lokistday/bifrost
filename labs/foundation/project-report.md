# 입력이 바뀌어도 믿을 수 있는 로그 요약기
## 1. 범위와 환경
대상은 제공된 오프라인 표본입니다. 도구/버전/OS, 원본 파일 해시, 시작·끝 시각을 적으세요.
## 2. 예상과 근거
실행 전 예상 / 파일·행·이벤트·프레임 ID / 대안 가설
## 3. 실제 실행
복사해 실행 가능한 명령 / 결과 파일 / 정상·거부·경계 사례
## 4. A에서 B로
달라진 조건 / 결과가 달라진 이유 / 본인이 추가한 새 반례
## 5. 수정과 재검증
원인 / 최소 수정 / 정상 기능 보존 / 실패 시 원상복구
## 6. 미확인과 다음 조사
자료로 확정할 수 없는 결론 / 추가로 필요한 근거
## 7. 자기 평가
각 루브릭을 0(없음)·1(설명만)·2(재현 근거 있음)으로 평가하고 근거 위치를 붙이세요.
자동 결과 일치와 코드·보고서 품질은 별개입니다. 개인 자료·비밀을 넣지 마세요.
