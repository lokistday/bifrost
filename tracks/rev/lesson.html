07

Reverse Engineering

소스 코드가 없어도 실행 파일의 동작을 알아낼 수 있을까?

주로 다루는 문제
실행 파일의 동작 파악, 함수·조건 분기 추론, 의심스러운 프로그램 분석
만나는 개념
어셈블리, 레지스터, 함수 호출, 정적·동적 분석, 디컴파일
잘 맞을 수 있는 관심
퍼즐처럼 단서를 연결하고, 관찰 근거를 바탕으로 동작을 추론하는 일을 즐긴다.
도움 되는 기초
C 기초와 함수·조건문 이해가 도움이 된다. 어셈블리는 작은 예제부터 익힌다.
첫 실습
직접 컴파일한 짧은 프로그램이나 공개 교육용 바이너리에서 문자열·함수·분기 흐름을 확인하고 추론을 기록한다.
학습 경로 C 기초 → 어셈블리·디버거 → 분석 근거와 추론을 구분한 보고서
WHAT YOU WILL BUILD

이 과정을 마치면

입력·분기·반환값을 근거로 프로그램의 동작을 추론하고 반례로 검증합니다.

01 · 바이너리와 정적 관찰

Ubuntu/WSL gcc·binutils 기준입니다. 명령어와 호출 규약은 x86-64와 ARM64에서 다르므로 이름을 고정해 외우지 않습니다.

  1. ELF·심볼·컴파일 옵션실행 파일의 정보와 분석 환경을 식별합니다.↗
  2. 명령어·비교·호출 읽기기계어 목록에서 호출과 조건 분기를 찾아 고수준 의미를 연결합니다.↗
  3. 문자열은 단서, 결론은 가설실행하지 않고 얻은 단서와 추정한 동작을 구분합니다.↗

02 · 동적 검증과 보고

출처를 모르는 바이너리를 실행하는 과정이 아니라 자신이 빌드한 예제를 검증합니다.

  1. 입력으로 분기 검증하기정적 분석 가설을 실제 실행과 중단점으로 확인합니다.↗
  2. 최적화 비교와 분석 보고서분석 결과가 적용되는 빌드·환경·입력을 명시합니다.↗
