01 / UNDERSTAND

먼저 이해하기

solve.py는 인자가 있으면 그 경로, 없으면 스크립트 옆 puzzle.txt를 읽습니다. 임의 파일을 실행하지 않고 텍스트로만 처리합니다. 경로·문자 인코딩·필수 필드·디코딩 실패는 서로 다른 오류 원인입니다.

예제의 dict 생성은 중복 키가 있으면 마지막 값을 남깁니다. 실제 도구로 발전시키려면 중복 필드 정책, 최대 입력 크기, 오류 메시지와 종료 코드를 정해야 합니다. 정상 입력 하나만 작동하는 것은 충분한 검증이 아닙니다.

CLI 도구는 정상 출력과 오류 출력을 구분하면 자동화에 연결하기 쉽습니다. 성공 결과는 stdout, 사용 오류·입력 오류는 stderr, 실패는 0이 아닌 종료 코드로 내보내는 방식을 정합니다. 오류 메시지에는 실패한 조건을 적되 불필요한 내부 정보는 줄입니다.

argparse는 파일 경로와 도움말 같은 실행 인터페이스를 정합니다. 실제 읽기·필드 검증·변환은 함수로 나누면 파일 없음과 Base64 오류를 각각 시험하기 쉽습니다. 예외를 잡은 뒤 성공 코드로 종료하면 상위 자동화가 실패를 놓칠 수 있습니다.

중복 payload를 마지막 값으로 덮어쓸지 거부할지 명확히 선택해야 합니다. 이 해설은 모호함을 줄이기 위해 중복 키를 거부하고 입력을 64 KiB로 제한합니다. 크기 제한은 변환 비용을 제한하는 조건이며 모든 파일 형식 공격을 해결하는 통제는 아닙니다.

자주 헷갈리는 지점

except Exception 뒤 아무 동작 없이 넘긴다.
예상한 입력 오류를 구체적으로 처리하고 실패를 호출자에게 전달합니다.
한 번 성공했으니 입력 검증도 완료됐다고 한다.
누락·중복·잘못된 문자·잘못된 인코딩·크기 경계를 별도 시험합니다.

03 / TRY IT YOURSELF

직접 바꾸고 확인하기

try/except를 추가해 파일 없음, payload 누락, 잘못된 Base64를 각각 설명하는 메시지와 0이 아닌 종료 코드로 처리하세요.

막혔을 때 힌트 보기

모든 예외를 무시하지 말고 실패 원인을 구분합니다. 학습용 원본과 수정본을 따로 보관하세요.

과제 해설과 예시 답안 보기
  1. 경로를 argparse로 받고 최대 크기·UTF-8·키=값·중복·payload 존재를 검사합니다.
  2. 두 단계 엄격 디코딩 뒤 중간 출력을 표시합니다.
  3. 입력 관련 예외는 stderr와 코드 2로 보고 정상 입력은 0으로 마칩니다. 아래 코드를 별도 파일로 저장해 정상/오류 표로 검증합니다.
예시 답안
import argparse
import base64
import binascii
from pathlib import Path
import sys

def solve(path):
    with path.open("rb") as f:
        data = f.read(65537)
    if len(data) > 65536:
        raise ValueError("input exceeds 64 KiB")
    fields = {}
    for line in data.decode("utf-8").splitlines():
        if not line.strip():
            continue
        if "=" not in line:
            raise ValueError("expected key=value")
        key, value = line.split("=", 1)
        if not key or key in fields:
            raise ValueError("empty or duplicate field")
        fields[key] = value
    if "payload" not in fields:
        raise ValueError("payload is required")
    value = fields["payload"].encode("ascii")
    outputs = []
    for step in range(1, 3):
        value = base64.b64decode(value, validate=True)
        outputs.append(f"step={step}: {value.decode('ascii')}")
    return outputs

parser = argparse.ArgumentParser()
parser.add_argument("path", type=Path)
args = parser.parse_args()
try:
    outputs = solve(args.path)
except (OSError, UnicodeError, ValueError, binascii.Error) as exc:
    print(f"input error: {exc}", file=sys.stderr)
    raise SystemExit(2)
print("\n".join(outputs))

결과를 판단하는 기준

정상은 step=1: Qmlmcm9zdA== / step=2: Bifrost와 종료 코드 0입니다. 파일 없음·payload 누락·중복 키·잘못된 Base64는 stderr 안내와 코드 2입니다.

학습 기록: 사용한 환경과 명령 → 바꾸기 전 예상 → 실제 결과 → 차이의 이유를 남기세요.
