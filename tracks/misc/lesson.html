이 과정의 완주 기준

차시별 독립 과제에서 조건을 바꿔 보고, 마지막에는 두 표본을 분석한 결과와 근거 보고서를 완성합니다.

차시 검색 · 목표별 경로 ↗
WHAT YOU WILL BUILD

이 과정을 마치면

입력 계약과 후보 공간을 명시하고 오류·반례·해의 개수·정규화의 의미를 검증하는 오프라인 분석 도구를 만듭니다.

01 · 단서와 데이터 파이프라인

암호 알고리즘의 안전성 대신 문제 분해와 데이터 표현을 다룹니다. Cryptography의 표현 차시와 연결해 볼 수 있습니다.

  1. 문제 분류와 가설 세우기문제의 입력·목표·제약을 먼저 정리합니다.↗
  2. 바이트 변환과 중간 검증변환 단계를 기록하고 잘못된 입력을 감지합니다.↗

02 · 도구와 재현

작은 스크립트를 입력과 오류를 설명할 수 있는 도구로 다듬습니다.

  1. 작은 CLI와 입력 검증파일 경로를 입력으로 받아 반복 가능한 처리를 만듭니다.↗
  2. 풀이 기록과 역변환 검증가설·실험·실패·검증을 다른 사람이 따라갈 수 있게 정리합니다.↗

03 · 구조화와 탐색

입력 문법·파일 목록·그래프를 명시적으로 모델링합니다.

  1. 정규식 전체 일치와 오류 행 보존이름 있는 그룹으로 고정 형식을 읽고 부분 일치·중복·오류 행을 구분합니다.↗
  2. 압축 목록·경로·자원 한도 검토파일을 추출하기 전에 목록과 경로 후보를 검사하고 안전한 추출의 추가 조건을 설명합니다.↗
  3. 그래프 탐색과 최단 경로의 조건방문 집합과 큐로 순환을 피하고 간선 수 기준 최단 경로를 구합니다.↗

04 · 제약과 재현성

해의 유일성과 분석 결과의 의미 보존을 검증합니다.

  1. 제약 조건과 해의 유일성 검증작은 후보 공간을 완전 탐색하고 조건 부족·모순·유일해를 구분합니다.↗
  2. 정규화·재현성·결과 무결성 검증동일한 의미의 입력을 결정적 형태로 정규화하고 값 변경과 순서 변경을 구분합니다.↗

05 · 컨테이너와 매체 자료

파일 매직·이미지 표본·바이트 통계를 서로 다른 관찰 층으로 읽습니다.

  1. 파일 매직과 바깥·안쪽 형식 구분짧은 시그니처와 구조 검증을 나누고 컨테이너와 내용의 형식을 단계별로 확인합니다.↗
  2. PPM 헤더와 RGB 픽셀 채널 읽기작은 텍스트 이미지의 크기·표본 개수·색 채널을 읽고 메타데이터와 실제 표본을 구분합니다.↗
  3. 바이트 분포와 엔트로피의 해석 한계표본의 빈도와 경험적 엔트로피를 계산하고 암호화·난수 판정으로 과장하지 않습니다.↗

06 · 자원 예산과 배치 재개

제한된 해제와 출처를 확인하는 반복 처리를 설계합니다.

  1. 해제 출력 한도와 스트림 경계 검증압축 입력·해제 출력 예산과 완료·여분 데이터 조건을 실제 코드로 검증합니다.↗
  2. 배치 출처와 재개 체크포인트 검증입력·변환 버전·작업 ID에 근거해 재실행 대상을 정하고 체크포인트의 한계를 기록합니다.↗
