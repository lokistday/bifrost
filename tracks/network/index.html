Network Security

네트워크 통신을 관찰하고 위협을 찾아 방어할 수 있을까?

주로 다루는 문제
프로토콜 이해, 트래픽 분석, 서비스 노출과 통신 보안, 네트워크 방어
만나는 개념
TCP/IP·DNS·TLS, PCAP, 라우팅·NAT·연결 상태, 방화벽, 탐지 지표, 증거 상관관계
잘 맞을 수 있는 관심
통신이 오가는 과정을 추적하고, 시스템 간 연결과 방어 방법을 이해하는 일이 흥미롭다.
도움 되는 기초
IP·HTTP·Linux 기초에서 시작해 웹 인가·클라우드 네트워크를 연결한다. 설계 모듈은 여러 분야를 함께 보는 중급 과정이다.
첫 실습
교육용 PCAP에서 DNS 질의와 TCP 연결을 찾아 흐름을 정리하고, 관찰 가능한 정보와 암호화로 보이지 않는 정보를 구분한다.
학습 경로 패킷·정책·경로 → IPv6·TCP 재조립 → DNS 캐시·MTU → 시간 창과 관측 결과 검증

WHAT YOU WILL BUILD

이 과정을 마치면

통신 경로와 상태를 설명하고 오탐·미탐과 사건 영향의 불확실성을 포함한 방어 검증안을 만듭니다.

01 · 분석을 위한 프로토콜

기초의 주소·HTTP 지식을 패킷 관찰로 연결합니다. 평문 HTTP와 실제 TLS 1.3 비교 자료를 읽고 관측 위치·증거·한계를 구분합니다.

  1. 계층·CIDR·관측 위치주소 범위와 관측 지점을 나누어 통신 경로를 설명합니다.↗
  2. PCAP·필터·스트림합성 캡처에서 프레임과 통신 스트림을 구분합니다.↗
  3. DNS·TCP 연결과 실패 분류이름 조회·핸드셰이크·응용 응답의 순서를 분석합니다.↗

02 · 경계와 정책 설계

세그먼트 분리, 최소 허용, 신원 검증을 함께 고려합니다. 제공 JSON은 실제 방화벽 설정 형식이 아닌 학습 모델입니다.

  1. TLS와 보이는 정보의 경계암호화된 통신에서 볼 수 있는 것과 없는 것을 구분합니다.↗
  2. 망 분리·신뢰 경계·관리 경로서비스 간 필요한 연결만 남기는 구간 구조를 설계합니다.↗
  3. 방화벽 정책과 회귀 검증기본 거부 정책에서 정상·거부·누락된 egress 사례를 테스트합니다.↗

03 · 탐지와 통합 방어

탐지 규칙의 한계를 설명하고, 웹·시스템·클라우드의 증거를 연결하는 최종 결과물을 만듭니다.

  1. 탐지 기준·오탐·추가 증거거부 이벤트의 반복을 신호로 만들고 해석의 한계를 검증합니다.↗
  2. 신원과 자산 중심의 Zero Trust내부 주소만으로 신뢰하지 않는 접근 판단을 설계합니다.↗
  3. 중간 종합: 작은 서비스 방어 설계분석 결과를 정책 변경·탐지·검증·롤백으로 연결합니다.↗

04 · 경로·상태·운영 검증

경로·주소 변환·연결 상태를 추적하고 탐지 수치와 사건 증거를 함께 평가합니다.

  1. 최장 접두사와 돌아오는 경로라우팅의 최장 접두사 선택과 보안 정책의 허용 판정을 구분합니다.↗
  2. NAT 주소·포트·시간으로 로그 연결공유 공인 IP만으로 내부 호스트를 단정하지 않고 변환 기록을 대조합니다.↗
  3. 연결 상태와 응답 허용의 조건새 연결 허용과 기존 연결의 응답 허용을 상태 전이로 설명합니다.↗
  4. 정밀도·재현율과 탐지 임계값탐지 결과를 오탐·미탐으로 나누고 임계값 변경의 비용을 계산합니다.↗
  5. 네트워크 증거 연결과 대응 판단여러 관측 지점을 연결해 접속 시도와 실제 영향을 구분합니다.↗

05 · 프로토콜 경계와 관측 품질

주소 계열·바이트 재조립·캐시·크기 제한·시간 경계가 분석과 방어 판단을 바꾸는 경우를 연습합니다.

  1. IPv6 주소 범위와 정책의 빈틈주소 계열과 인터페이스 범위를 구분하고 IPv4 규칙의 적용 한계를 확인합니다.↗
  2. 스트림 재조립과 누락·겹침패킷 도착 순서와 바이트 스트림을 구분하고 재조립의 불확실성을 보고합니다.↗
  3. DNS TTL과 부정 응답 캐시캐시 유효 시간과 NXDOMAIN·NODATA의 적용 범위를 구분합니다.↗
  4. MTU·PMTUD와 큰 전송의 실패작은 연결 확인과 큰 전송의 성공을 구분하고 헤더를 제외한 바이트 예산을 계산합니다.↗
  5. 사건 시각·지연 도착과 세션 경계수집 순서와 사건 순서를 나누고 지연 이벤트가 집계에 주는 영향을 검증합니다.↗
