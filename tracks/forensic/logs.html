01 / UNDERSTAND

먼저 이해하기

auth.csv의 한 행은 하나의 기록입니다. id는 이 실습의 증거 식별자, time은 시각과 시간대, source는 관찰된 출발지입니다. IP 하나가 사람 한 명을 뜻하지 않으며 사용자 이름도 실제 행위자를 자동으로 증명하지 않습니다.

E02~E04는 bob 로그인 거부, E05는 같은 계정의 성공, E06은 파일 읽기입니다. 시간상 이어진다는 사실로 계정 침해라고 단정하지 않습니다. 비밀번호 오타, 자동화, 공유 주소 같은 대안과 확인할 자료를 함께 적습니다.

먼저 열 이름을 읽고 한 행이 무엇을 뜻하는지 정합니다. event는 기록 시스템이 남긴 결과이고 user는 그 결과에 연결된 계정 이름입니다. source만으로 개인을 특정하거나 login_ok만으로 정상 사용을 확정하면 근거가 부족합니다.

이 표본에서는 E02~E04가 같은 계정 bob과 출발지 198.51.100.8에 대해 10초 간격으로 기록됩니다. E05와 E06도 같은 계정·출발지입니다. 이 연결은 조사할 범위를 좁히지만 세션 식별자가 없어서 하나의 세션이었다고 확정할 수 없습니다.

가설은 반증 가능한 질문으로 씁니다. 예를 들어 계정 탈취 가설에는 MFA 결과·장치·세션을, 정상 사용자의 반복 오타 가설에는 사용자 확인과 평소 로그인 패턴을 요청합니다. 없는 필드의 값을 상상해 채우지 않습니다.

자주 헷갈리는 지점

3번 실패했으므로 무조건 무차별 대입이라고 단정한다.
기준선·시간 범위·다른 계정 시도·자동화 여부를 확인하고 표본에서 관찰한 사실만 먼저 적습니다.
file_read를 외부 유출과 같은 뜻으로 쓴다.
읽기와 외부 전송은 다른 행위입니다. 전송량·목적지·애플리케이션 로그가 추가로 필요합니다.

02 / WORKED EXAMPLE

따라 하며 관찰하기

먼저 수정하지 않은 원본으로 아래 기준 예제를 확인하세요. 원본 폴더를 보관하고 전체 폴더의 작업 사본에서 다음 변경 단계를 진행합니다. 아래 예상 결과는 변경 전 기준입니다.

처음 상태의 전체 예제

터미널 명령 · 이 분야의 작업 사본 폴더 · CSV 관찰 · Python 3

변경 전 예상 결과와 해석

E01~E06 여섯 이벤트가 보이고, login_denied는 3건입니다.

이제 단계별로 바꾸고 관찰하기

  1. 사건 수와 필드 확인

    CSV 파서로 행을 읽고 전체 6건과 필수 열을 확인합니다. 단순 쉼표 분할보다 csv 모듈을 쓰면 따옴표 처리 규칙을 지킬 수 있습니다.

    Python 부분 코드 · 앞 단계의 변수·객체를 유지한 같은 스크립트 · CSV 관찰 · Python 3
    import csv
from pathlib import Path
with Path("auth.csv").open(encoding="utf-8", newline="") as f:
    rows = list(csv.DictReader(f))
print(len(rows))
print(list(rows[0]))
    관찰할 결과
    6과 id, time, host, user, event, source가 보입니다.

  2. 실패 묶음에서 공통값 찾기

    이벤트 종류로 먼저 범위를 좁힌 뒤 계정과 출발지를 비교합니다. 기록 순서를 원인이라고 해석하지 말고 관찰 열을 유지합니다.

    Python 부분 코드 · 앞 단계의 변수·객체를 유지한 같은 스크립트 · CSV 관찰 · Python 3
    denied = [r for r in rows if r["event"] == "login_denied"]
print([(r["id"], r["user"], r["source"]) for r in denied])
    관찰할 결과
    E02, E03, E04 모두 bob / 198.51.100.8입니다.

  3. 사실에서 조사 질문으로 이동

    사실은 E05의 login_ok와 E06의 file_read입니다. 가설은 계정 침해 또는 정상 사용입니다. 각각을 구별할 추가 자료를 붙이고 자료가 없으면 미확정으로 남깁니다.

    관찰할 결과
    사실 3개, 대안 가설 2개, 각 가설을 검증할 요청 자료가 분리된 표가 됩니다.
