WHAT YOU WILL BUILD

이 과정을 마치면

작은 프로그램과 파일을 다루고, 요청 흐름을 설명하며 재현 가능한 학습 기록을 만듭니다.

01 · 실습 환경과 파일

Windows는 WSL Ubuntu, Linux는 Ubuntu 터미널을 기준으로 합니다. Python 차시는 macOS와 Windows Python에서도 진행할 수 있습니다.

  1. 실습 환경 준비와 첫 실행명령을 입력할 환경과 도구 버전을 구분하고 Python 예제를 실행합니다.↗
  2. 경로와 작업용 사본현재 경로를 기준으로 파일을 만들고 사본을 구분합니다.↗

02 · Python을 작은 단계로

값 → 분기와 반복 → 파일 처리 순서로 진행합니다. 코드는 파일에 저장한 후 python3 파일이름.py로 실행합니다.

  1. 변수·문자열·자료형이름에 값을 담고 숫자 계산과 문자열 출력을 구분합니다.↗
  2. 조건·반복·함수반복되는 판정을 함수로 묶고 결과를 셉니다.↗
  3. CSV 읽기와 오류 좁히기파일을 행 단위 데이터로 읽고 조건에 맞는 항목을 추출합니다.↗

03 · 시스템·통신·기록

C·Linux는 설치된 Ubuntu/WSL 환경을 사용합니다. 이후 관심 분야와 병행할 수 있습니다.

  1. C 컴파일과 주소·포인터소스와 실행 파일을 구분하고 값과 주소의 관계를 확인합니다.↗
  2. Linux 권한과 파이프파일의 읽기·쓰기 권한과 명령 사이의 데이터 흐름을 확인합니다.↗
  3. IP·포트·DNS와 전송이름 조회와 서비스 연결이 서로 다른 단계임을 설명합니다.↗
  4. HTTP 요청과 응답 읽기메서드·경로·헤더·본문을 실제 형식에서 찾습니다.↗
  5. Git과 재현 가능한 README변경 내용을 커밋하고 다른 사람이 따라 할 실행 기록을 만듭니다.↗
