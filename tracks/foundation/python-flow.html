01 / UNDERSTAND

먼저 이해하기

if는 조건이 참일 때만 블록을 실행합니다. for는 자료의 항목을 하나씩 꺼냅니다. Python은 들여쓰기로 블록을 구분하므로 탭과 공백을 섞지 않고 같은 깊이의 줄을 맞춥니다.

함수는 입력에서 결과를 만드는 작은 단위입니다. return은 호출한 곳으로 값을 돌려주고 print는 화면에 보여 줍니다. 상태 판정을 함수로 분리하면 나중에 입력과 출력을 따로 검사하기 쉽습니다.

세 기능을 한 번에 읽기 어렵다면 판정 하나 → 목록 순회 → 함수 호출 순으로 나눕니다. status == "denied"의 결과는 True 또는 False인 불리언입니다. if는 그 결과를 보고 실행할 블록을 선택합니다.

count += 1은 현재 count에 1을 더해 저장합니다. 반복 시작 전 한 번만 0으로 초기화해야 누적 횟수가 남습니다. 각 회차의 status와 count를 표로 적으면 코드의 실행 순서를 눈으로 따라갈 수 있습니다.

def 줄은 함수의 동작을 정의하며 함수 본문은 호출할 때 실행됩니다. return으로 받은 값을 if의 조건으로 쓸 수 있습니다. print만 하는 함수로 바꾸면 화면에는 글자가 보여도 호출 결과가 같은 판정값이 되는 것은 아닙니다.

자주 헷갈리는 지점

=와 ==를 혼동한다.
=는 이름에 값을 연결하고 ==는 두 값이 같은지 비교합니다.
함수 정의만 쓰면 바로 실행된다고 생각한다.
is_denied("denied")처럼 호출하는 줄을 찾아 입력과 반환값을 연결합니다.

02 / WORKED EXAMPLE

따라 하며 관찰하기

먼저 수정하지 않은 원본으로 아래 기준 예제를 확인하세요. 원본 폴더를 보관하고 전체 폴더의 작업 사본에서 다음 변경 단계를 진행합니다. 아래 예상 결과는 변경 전 기준입니다.

처음 상태의 전체 예제

Python 코드 · 안내된 .py 파일에 저장해 실행 · Python 3 · flow.py
def is_denied(status):
    return status == "denied"

count = 0
for status in ["ok", "denied", "ok", "denied"]:
    if is_denied(status):
        count += 1
print(count)

03 / TRY IT YOURSELF

직접 바꾸고 확인하기

목록에 denied 하나와 ok 하나를 더하고 결과를 예측하세요. 함수에 unknown을 넣었을 때 False가 나오는 이유도 적습니다.

막혔을 때 힌트 보기

==는 비교, =는 대입입니다. count = 0은 반복문 밖에 있어야 누적됩니다.

과제 해설과 예시 답안 보기
  1. 원래 목록 뒤에 "denied", "ok"를 한 항목씩 추가합니다. 판정에 맞는 항목은 세 개이므로 count는 3입니다.
  2. is_denied("unknown")은 문자열이 "denied"와 같지 않아 False입니다. 이 예제는 unknown을 별도로 처리하는 정책까지 정의하지 않았음을 기록합니다.
  3. count = 0이 반복문 밖에 있는지, print(count)가 최종 합계를 출력할 위치에 있는지 확인합니다.

결과를 판단하는 기준

수정한 본문 예제의 최종 출력은 3입니다. 함수 단독 호출은 denied → True, unknown → False입니다.

학습 기록: 사용한 환경과 명령 → 바꾸기 전 예상 → 실제 결과 → 차이의 이유를 남기세요.

05 / VERIFY

이해한 내용을 점검하기

답을 고른 뒤 이유까지 확인하세요. 점수는 저장하지 않습니다.

1. 매 회차마다 count = 0을 for 블록 안 첫 줄에 두면 왜 전체 건수를 제대로 셀 수 없을까요?

정답과 이유 읽기

정답: 이전 회차의 누적값을 매번 지우기 때문이다.

누적은 이전 값을 이어받아야 합니다. 초기화는 반복 전 한 번, 조건에 맞는 증가만 반복 안에서 수행합니다.

2. return status == "denied"를 print(status == "denied")로만 바꾸면 호출한 곳의 if 판정도 같을까요?

정답과 이유 읽기

정답: 같지 않다. print의 반환값은 판정값 True가 아니다.

표시와 반환은 다릅니다. 명시적 return이 없는 함수는 None을 반환하므로 if에서 원래의 불리언 판정을 얻지 못합니다.
