01 / UNDERSTAND

먼저 이해하기

절대 경로는 루트에서 시작하는 전체 위치이고 상대 경로는 현재 폴더에서 시작합니다. ~/bifrost-practice는 홈 아래의 폴더입니다. 공백이 있는 파일 이름은 따옴표로 감싸야 하나의 인자로 전달됩니다.

분석에서는 원본과 작업용 파일을 구분합니다. cp는 사본을 만들고 mv는 이름이나 위치를 바꿉니다. 아래는 Ubuntu 명령입니다. 다운로드한 notes.txt가 있는 폴더에서 시작하고, 원본 내용을 먼저 읽으세요.

현재 폴더를 바꾸면 같은 상대 경로도 다른 파일을 가리킵니다. ./notes.txt는 현재 폴더의 파일이고 ../notes.txt는 한 단계 위 폴더의 파일입니다. ~는 셸이 홈 디렉터리로 확장하는 표기이며 루트 디렉터리 /와 다릅니다.

사본을 만들기 전 원본 내용을 한 번 확인하면 이후 차이를 설명할 기준점이 생깁니다. 이름이 copy.txt여도 원본을 덮어쓰면 기준을 잃습니다. 명령의 출발 파일과 도착 파일을 한 줄씩 읽는 습관을 들이세요.

자주 헷갈리는 지점

>와 >>를 같은 의미로 생각한다.
>는 해당 파일을 새로 쓰고 >>는 덧붙입니다. 실행 전 대상 경로와 연산자를 함께 확인합니다.
폴더를 이동했는데 같은 상대 경로가 통할 것으로 기대한다.
pwd로 기준점을 다시 확인합니다. 오류가 났다고 파일이 삭제됐다고 단정하지 않습니다.

02 / WORKED EXAMPLE

따라 하며 관찰하기

  1. 경로의 기준점 잡기

    pwd 결과를 적고 ls로 notes.txt가 보이는지 확인합니다. 다른 폴더라면 파일 관리자로 찾은 위치로 이동한 뒤 시작합니다.

    작게 나눠 확인하기
    pwd
ls
cat notes.txt
    관찰할 결과
    notes.txt는 Bifrost, Linux practice, Keep evidence의 세 줄입니다.

  2. 원본을 작업 폴더에 복사하기

    mkdir -p는 폴더가 이미 있어도 사용할 수 있게 합니다. cp의 첫 인자는 원본, 두 번째 인자는 사본 경로입니다.

    작게 나눠 확인하기
    mkdir -p work
cp notes.txt work/copy.txt
cat work/copy.txt
    관찰할 결과
    사본에서도 같은 세 줄이 나옵니다.

  3. 사본만 바꾸고 양쪽 확인하기

    >>는 사본 끝에 한 줄을 덧붙입니다. 원본을 다시 읽어 변화가 없는지 확인합니다.

    작게 나눠 확인하기
    printf "Only in copy
" >> work/copy.txt
wc -l notes.txt work/copy.txt
    관찰할 결과
    원본은 3줄, 한 번 추가한 사본은 4줄입니다. 반복 실행하면 사본 줄 수는 더 늘어납니다.

전체 예제 연결하기

예제 · 명령 또는 관찰 절차
pwd
cat notes.txt
mkdir -p work
cp notes.txt work/copy.txt
ls work
cat work/copy.txt

예상 결과와 해석

work 안에 copy.txt가 보이고, 원본과 사본 모두 Bifrost / Linux practice / Keep evidence 세 줄을 포함합니다.
03 / TRY IT YOURSELF

직접 바꾸고 확인하기

work/copy.txt에만 한 줄을 추가하고 원본과 사본을 비교하세요. 원본이 그대로인지 다시 읽어 확인합니다.

막혔을 때 힌트 보기

Ubuntu에서는 printf와 >>로 한 줄을 추가할 수 있습니다. >는 기존 내용을 덮어쓰므로 차이를 확인하세요.

과제 해설과 예시 답안 보기
  1. notes.txt를 work/copy.txt로 복사한 뒤 사본에만 한 줄을 추가합니다.
  2. cat notes.txt와 cat work/copy.txt를 각각 실행해 원본 세 줄, 사본 네 줄을 비교합니다.
  3. pwd 결과에 /notes.txt를 붙이면 이 실습 파일의 절대 경로 예시가 됩니다. work/copy.txt는 현재 위치 기준 상대 경로입니다.

결과를 판단하는 기준

새로 만든 사본에 한 번만 추가하면 원본 3줄·사본 4줄입니다. 원본의 마지막 줄은 Keep evidence로 유지됩니다.

학습 기록: 사용한 환경과 명령 → 바꾸기 전 예상 → 실제 결과 → 차이의 이유를 남기세요.

04 / VERIFY

이 정도면 다음으로

이해한 내용을 점검하기

답을 고른 뒤 이유까지 확인하세요. 점수는 저장하지 않습니다.

1. 현재 위치가 /home/learner/labs일 때 work/copy.txt가 가리키는 위치는?

정답과 이유 읽기

정답: /home/learner/labs/work/copy.txt

상대 경로는 현재 폴더 뒤에 이어서 해석합니다. /로 시작하는 경로는 루트에서 시작합니다.

2. 원본을 유지하면서 사본 뒤에 한 줄을 추가하려고 합니다. 알맞은 대상과 연산자는?

정답과 이유 읽기

정답: printf의 결과를 >> work/copy.txt로 보낸다.

>>는 지정한 사본에 덧붙입니다. > notes.txt는 원본을 덮어쓰고 mv는 사본을 만들지 않고 원본 위치를 바꿉니다.

  • 절대·상대 경로를 각각 예로 들었다.
  • 사본 변경 후 원본이 유지되는 것을 확인했다.
