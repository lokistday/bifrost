01 / UNDERSTAND

먼저 이해하기

변수는 값에 붙이는 이름입니다. minutes = 15는 이름에 정수를 연결하지만 "15"는 문자열입니다. 정수끼리 +하면 합이 되고 문자열끼리 +하면 이어 붙입니다. 따라서 입력값을 계산하려면 자료형을 확인해야 합니다.

f 문자열 안의 중괄호는 값을 출력문에 넣습니다. hello.py의 minutes * 2는 정수 곱셈이므로 30입니다. 문자열과 숫자를 무작정 더하면 TypeError가 날 수 있습니다. 오류 메시지 마지막 줄의 유형과 발생 줄을 함께 읽으세요.

대입문은 오른쪽 식을 먼저 계산한 뒤 왼쪽 이름에 연결합니다. minutes = minutes + 5는 기존 값을 읽고 5를 더한 새 값을 저장한다는 뜻입니다. 수학에서의 등식과 읽는 방향이 다릅니다.

문자열 "20"을 int로 바꾸면 숫자 계산이 가능하지만 모든 문자열이 숫자는 아닙니다. int("twenty")는 ValueError가 납니다. 사용자 입력을 받는 프로그램에서는 변환 실패도 정상적으로 처리할 경우에 포함해야 합니다.

자주 헷갈리는 지점

값이 20처럼 보여도 자료형을 확인하지 않는다.
type으로 종류를 확인하고, 계산과 문자열 표시를 별도 단계로 둡니다.
예제 파일을 바꾼 후 다른 이름의 파일을 실행한다.
편집한 경로와 실행 인자를 함께 기록해 같은 파일을 다루는지 확인합니다.

03 / TRY IT YOURSELF

직접 바꾸고 확인하기

숫자 minutes를 20으로 바꾸고 계산 결과를 먼저 예측하세요. int("20")와 "20"의 자료형도 비교합니다.

막혔을 때 힌트 보기

type(value).__name__으로 자료형을 확인하세요. 따옴표의 유무를 살펴봅니다.

과제 해설과 예시 답안 보기
  1. minutes = 20으로 수정하면 minutes * 2는 40입니다. 기존 예제의 고정 문자열 "15" + "15"는 바꾸지 않았다면 계속 1515입니다.
  2. int("20")은 int이고 "20"은 str임을 출력합니다. 값 변경과 자료형 변경을 구분해 설명합니다.
  3. hello.py에서 minutes를 바꾼 실험과 새 values.py의 실험을 파일 이름별로 나누어 기록합니다.

1. minutes = 20일 때 print("20" + "20")의 출력이 40이 아닌 이유는?

정답과 이유 읽기

정답: 문자열끼리의 +는 문자들을 이어 붙이기 때문이다.

따옴표 안의 값은 str입니다. 정수 계산을 하려면 int("20")처럼 변환하여 더해야 합니다.

2. int("twenty")를 실행해 ValueError가 났습니다. 무엇을 확인해야 할까요?

정답과 이유 읽기

정답: 문자열이 정수 형식으로 변환 가능한 입력인지 확인한다.

int는 임의의 영어 단어를 숫자로 해석하지 않습니다. 입력 형식과 변환 실패 처리를 확인해야 합니다.
