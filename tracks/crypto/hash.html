01 / UNDERSTAND

먼저 이해하기

암호학적 해시는 가변 길이 입력을 고정 길이 요약으로 만듭니다. SHA-256의 출력은 256비트, 즉 32바이트이고 Hex로는 64문자입니다. 해시는 복호화하는 암호문이 아닙니다.

누구나 파일과 해시를 함께 바꿀 수 있다면 단순 해시만으로 발신자를 인증할 수 없습니다. 비교하는 기준 해시를 신뢰할 경로로 확보해야 합니다. 비밀번호에는 빠른 일반 해시만 쓰지 않고 전용 KDF를 사용합니다.

digest()는 32바이트 요약을, hexdigest()는 그 바이트의 64자리 Hex 표현을 반환합니다. 표현이 다를 뿐 같은 SHA-256 결과입니다. 문자열 길이와 비트 길이를 혼동하지 않도록 단위를 붙입니다.

같은 입력 바이트는 같은 해시가 됩니다. 느낌표 하나나 개행 하나가 달라지면 일반적으로 전혀 다른 요약이 나옵니다. 해시가 다르면 입력이 다르다고 알 수 있지만 어느 위치가 바뀌었는지와 누가 바꾸었는지는 해시가 설명하지 않습니다.

SHA-256은 빠르게 계산하도록 설계된 일반 해시입니다. 다운로드 파일의 변경 확인에는 유용하지만 저엔트로피 비밀번호에는 공격자가 많은 후보를 빠르게 시험할 수 있습니다. 목적에 맞는 도구 선택이 필요하다는 점을 password 차시와 연결합니다.

자주 헷갈리는 지점

해시가 다르면 공격자가 바꿨다고 확정한다.
바이트 차이는 알 수 있지만 개행·전송 오류·편집 등 변경 원인은 별도로 확인합니다.
비밀번호를 SHA-256 한 번으로 저장하면 충분하다고 생각한다.
비밀번호에는 salt와 비용을 가진 전용 KDF를 사용하며 최신 지침과 구현을 확인합니다.

  1. 두 표현의 단위 비교

    같은 해시 객체에서 bytes와 Hex 결과를 꺼내 길이를 확인합니다.

    Python 부분 코드 · 앞 단계의 변수·객체를 유지한 같은 스크립트 · 해시 비교 · Python 3

  2. 같음과 한 바이트 차이 비교

    같은 입력 재계산은 같고 Bifrost!와는 다릅니다. “hash가 매번 무작위로 바뀐다”는 오해를 직접 반박합니다.

    Python 부분 코드 · 앞 단계의 변수·객체를 유지한 같은 스크립트 · 해시 비교 · Python 3
    a = hashlib.sha256(b"Bifrost").digest()
print(a == hashlib.sha256(b"Bifrost").digest())
print(a == hashlib.sha256(b"Bifrost!").digest())
