01 / UNDERSTAND

먼저 이해하기

CSV는 쉼표로 나눈 표이지만 따옴표 안에 쉼표가 들어갈 수 있습니다. 단순 split 대신 csv.DictReader를 쓰면 첫 행의 열 이름으로 각 값을 읽을 수 있습니다. 텍스트 인코딩도 파일을 여는 규칙의 일부입니다.

제공된 summarize.py는 스크립트와 같은 폴더의 events.csv를 읽습니다. Path(__file__)을 쓰므로 터미널의 현재 경로가 달라도 입력 파일을 찾습니다. KeyError는 열 이름, FileNotFoundError는 파일 위치, UnicodeDecodeError는 인코딩을 먼저 점검할 신호입니다.

DictReader가 만드는 한 행은 {"user": "bob", "status": "denied"}처럼 열 이름과 문자열 값을 연결한 사전입니다. rows는 이런 행들의 목록입니다. denied는 원본 rows에서 조건을 만족한 행만 골라 만든 새 목록이므로 전체 건수와 거부 건수를 따로 셀 수 있습니다.

한 줄의 축약식을 처음 읽기 어렵다면 for와 if로 펼쳐 읽습니다. 파일을 여는 단계, 표로 읽는 단계, 거부 행을 고르는 단계, 출력 단계를 나누면 오류가 어느 경계에서 났는지 좁힐 수 있습니다. 무조건 except로 숨기면 이 근거를 잃습니다.

자주 헷갈리는 지점

CSV를 단순 split(",")으로 언제나 읽는다.
따옴표 안의 쉼표 등 표 형식을 처리할 수 있도록 csv 모듈을 사용합니다.
CSV의 숫자처럼 보이는 셀을 자동 정수로 생각한다.
DictReader의 기본 값은 문자열입니다. 계산이 필요할 때 명시적으로 검증·변환합니다.

03 / TRY IT YOURSELF

직접 바꾸고 확인하기

events.csv 사본에 dana,denied 행을 추가해 합계 5건·거부 3건을 확인하세요. 파일 이름을 잠시 바꿔 오류의 마지막 줄과 원인을 기록한 뒤 복구합니다.

막혔을 때 힌트 보기

스크립트와 CSV를 함께 두세요. 열 이름 user,status는 수정하지 말고 데이터를 추가합니다.

과제 해설과 예시 답안 보기
  1. events.csv를 events-original.csv로 복사해 보관한 뒤 작업 events.csv의 마지막에 dana,denied를 새 행으로 추가합니다.
  2. 실행 결과가 events=5 denied=3이며 사용자 목록 끝에 dana가 추가되는지 확인합니다.
  3. 파일 이름을 잠깐 바꿔 FileNotFoundError를 확인하고 되돌립니다. KeyError가 나면 user,status 머리글을 원본과 비교합니다. 오류를 관찰한 뒤 반드시 입력 파일을 복구합니다.

결과를 판단하는 기준

추가 행을 한 번 넣으면 총 5건·거부 3건입니다. 파일 이름 복구 후에도 이 결과로 다시 실행되어야 합니다.
