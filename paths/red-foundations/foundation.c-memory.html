01 / UNDERSTAND

먼저 이해하기

Python은 인터프리터로 코드를 실행하지만 이 C 예제는 먼저 gcc로 기계어 실행 파일을 만듭니다. -Wall -Wextra는 경고를 늘리고 -g는 디버깅 정보를 넣습니다. 소스를 바꿨다면 다시 컴파일해야 실행 파일에 반영됩니다.

&value는 변수의 주소, pointer는 그 주소를 저장한 변수, *pointer는 그 위치의 값입니다. 주소를 출력할 때는 %p와 void * 변환을 사용합니다. 주소 숫자는 실행마다 달라도 정상이며 값의 변화와 별개입니다.

C에서 int value = 7은 정수 객체를 만들고 int *pointer = &value는 그 객체의 위치를 가리키게 합니다. pointer라는 이름의 변수와 value라는 객체는 별개입니다. *pointer = 9는 가리키는 객체에 쓰므로 이후 value를 읽으면 9입니다.

주소를 정수값 7이나 9와 섞어 계산할 필요는 없습니다. 종이에 value 상자와 pointer 상자를 그리고 화살표를 연결하세요. 선언의 *는 포인터 자료형을 나타내고 식의 *pointer는 그 위치를 읽거나 쓰는 역참조라는 차이부터 익힙니다.

자주 헷갈리는 지점

pointer와 *pointer를 같은 값으로 읽는다.
pointer는 위치, *pointer는 그 위치의 객체로 나누어 표기합니다.
실행할 때마다 주소가 달라지면 잘못된 것으로 본다.
주소 배치는 환경에 따라 달라질 수 있습니다. 이 차시의 판단 기준은 값의 관계와 변경 결과입니다.

02 / WORKED EXAMPLE

따라 하며 관찰하기

먼저 수정하지 않은 원본으로 아래 기준 예제를 확인하세요. 원본 폴더를 보관하고 전체 폴더의 작업 사본에서 다음 변경 단계를 진행합니다. 아래 예상 결과는 변경 전 기준입니다.

처음 상태의 전체 예제

터미널 명령 · 이 분야의 작업 사본 폴더 · Ubuntu/WSL · GCC
gcc -Wall -Wextra -g addresses.c -o addresses
./addresses

변경 전 예상 결과와 해석

value=7 dereferenced=7
address=0x... (환경마다 다름)
after=9

이제 단계별로 바꾸고 관찰하기

  1. 소스에서 출력 순서 찾기

    addresses.c에서 value 초기화, pointer 연결, 첫 출력, *pointer 대입, 마지막 출력 줄을 차례로 표시합니다. 실행하기 전에 첫 값과 마지막 값을 예측합니다.

  2. 경고와 실행 결과를 따로 읽기

    -o 뒤 이름이 생성할 실행 파일입니다. 컴파일에 실패했다면 이전 실행 파일이 남아 있을 수 있으므로 성공 여부를 먼저 확인합니다.

    터미널 명령 · 이 분야의 작업 사본 폴더 · Ubuntu/WSL · GCC
    gcc -Wall -Wextra -g addresses.c -o addresses
./addresses
    관찰할 결과
    value=7 dereferenced=7
address=0x...
after=9

  3. 화살표를 통한 쓰기 확인하기

    *pointer = 9를 *pointer = 12로 바꿉니다. value의 초기값은 유지하고 다시 빌드하면 같은 대상에 대한 쓰기만 변경한 실험이 됩니다.

    터미널 명령 · 이 분야의 작업 사본 폴더 · Ubuntu/WSL · GCC
    gcc -Wall -Wextra -g addresses.c -o addresses
./addresses
    관찰할 결과
    첫 값은 value=7 dereferenced=7이고 마지막 값은 after=12입니다. 주소는 고정하지 않습니다.
03 / TRY IT YOURSELF

직접 바꾸고 확인하기

마지막 대입을 *pointer = 12로 바꾸고 다시 컴파일하세요. value를 직접 바꾸지 않았는데 결과가 달라진 이유를 그림으로 그립니다.

막혔을 때 힌트 보기

수정 후에도 9라면 컴파일 성공 여부와 실행 파일 경로를 확인하세요.

과제 해설과 예시 답안 보기
  1. *pointer = 12로 바꾸고 컴파일 오류 없이 addresses를 생성합니다.
  2. 실행 전에는 value → 7, pointer → value의 주소로 그립니다. 대입 후에는 화살표가 그대로이며 value 내용만 12로 바뀝니다.
  3. 두 출력 사이에 value를 직접 대입한 줄이 없는 것을 근거로 역참조의 효과를 설명합니다.

결과를 판단하는 기준

value=7 dereferenced=7 / address=환경별 주소 / after=12입니다.

학습 기록: 사용한 환경과 명령 → 바꾸기 전 예상 → 실제 결과 → 차이의 이유를 남기세요.
