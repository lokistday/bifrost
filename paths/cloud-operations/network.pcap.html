01 / UNDERSTAND

먼저 이해하기

PCAP은 시점별 패킷 바이트를 담는 파일입니다. 이 표본은 합성한 DNS 2프레임과 TCP/HTTP 6프레임으로 총 8개이며 실제 사용자의 통신은 아닙니다. 실시간 캡처 권한 없이 Wireshark에서 파일 열기만으로 학습할 수 있습니다.

표시 필터는 이미 담긴 패킷 중 보이는 것을 고릅니다. 캡처 필터와 문법·적용 시점이 다릅니다. tcp.stream은 관련 TCP 통신을 묶는 분석 도구의 인덱스이며 패킷 안에 원래 들어 있는 전역 세션 ID가 아닙니다.

프레임 목록의 한 행은 캡처에 저장된 하나의 프레임입니다. 응용 요청 하나가 여러 TCP 세그먼트로 나뉠 수 있으므로 패킷 수와 요청 수는 같지 않습니다. 재조립된 스트림은 응용 바이트의 흐름을 보기 위한 보기입니다.

DNS 표시 필터를 걸어도 나머지 패킷이 파일에서 지워지는 것은 아닙니다. 전체 8개 중 현재 보이는 2개라는 식으로 전체 수와 표시 수를 나누어 기록합니다. 필터를 지우면 원래 프레임이 다시 보입니다.

Follow TCP Stream은 선택한 연결에 관련된 데이터를 방향별로 모아 줍니다. 스크린샷만 남기기보다 프레임 번호·필터 식·관찰 문자열을 함께 기록하면 다른 사람이 같은 지점으로 돌아갈 수 있습니다. 이 표본에 없는 연결을 추측해 전체 환경을 일반화하지 않습니다.

자주 헷갈리는 지점

6개 TCP 프레임을 HTTP 요청 6건으로 센다.
연결 시작·ACK·응답도 프레임입니다. 응용 요청은 HTTP 필드나 재조립된 스트림으로 확인합니다.
필터 식 없이 캡처 화면만 보고한다.
파일 이름·프레임 번호·필터·관찰 문자열을 함께 남겨 재현성을 확보합니다.
