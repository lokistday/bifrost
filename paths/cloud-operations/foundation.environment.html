01 / UNDERSTAND

먼저 이해하기

터미널은 명령을 입력하는 창이고, 셸은 그 명령을 해석하는 프로그램입니다. PowerShell과 Ubuntu의 Bash는 문법과 경로가 다릅니다. 아래 설치 명령은 Ubuntu에서만 실행합니다. Windows에서 Ubuntu가 아직 없다면 먼저 Linux 시작 가이드를 따라 준비하세요.

python3는 Python 인터프리터, gcc는 C 컴파일러, gdb는 디버거입니다. 버전 출력은 설치 확인이지 학습 완료 자체는 아닙니다. 실습 ZIP을 풀고 foundation 폴더를 터미널의 현재 위치로 만든 뒤 hello.py를 실행합니다. Windows Python만 쓸 때는 python3 대신 py -3를 사용합니다.

명령은 보통 프로그램 이름, 옵션, 인자 순서입니다. python3 --version의 --version은 버전을 묻는 옵션이고 python3 hello.py의 hello.py는 실행할 파일입니다. 문서에 보이는 $나 >>>는 입력 위치를 나타내는 프롬프트일 수 있으므로 명령에 함께 붙이지 않습니다.

설치가 끝났는지, 입력 파일이 있는지, 실행이 성공했는지는 따로 확인합니다. command not found는 명령 탐색 문제이고 can't open file은 Python은 실행됐지만 파일 경로를 찾지 못한 상황입니다. 처음부터 재설치하기보다 어느 단계에서 막혔는지를 기록하세요.

자주 헷갈리는 지점

문서의 $ 또는 >>>까지 복사한다.
프롬프트와 명령 본문을 구분하고 python3부터 입력합니다.
출력이 안 나오면 모든 설치를 반복한다.
명령을 못 찾는지, 파일을 못 찾는지, 프로그램 내부 오류인지 마지막 오류 줄로 나눕니다.
